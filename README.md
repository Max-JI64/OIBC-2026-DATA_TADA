# OIBC-2026-DATA_TADA
OIBC 2026 공모전 - DATA_TADA팀

현재는 사용자 요청에 따라 예측 모델링을 중단하고 데이터 자체를 분석하는 단계다. [DA-012 발전 유형별 기상 반응 차이](reports/2026-10-21_15_발전유형별_기상반응_차이_분석.md)를 완료했다. 전체 80개소와 같은 B 지점 7곳/41개소에서 유형의 운량/습도 기울기 차이를 비교했다. 일부 조건의 차이는 남았으나 연도/자료/척도/지점 구성에서 일관된 유형 특성은 확보하지 못해, 곡선의 두 유형을 기상 반응의 두 집단으로 해석하는 판단을 보류했다. 반응이 같다는 입증이나 개별 발전소의 모든 이질성 검정은 아니다.

초기 DA-001~005와 후속 DA-010/007/011/012는 각 사전 범위에서 완료했다. [결과 종합 검토](reports/2026-10-21_11_분석결과_종합과_후속질문_검토.md)의 세 권장 범위와 추가 선택 DA-012를 마쳤다. 남은 DA-006/009와 기존 EDA-004는 변수 압축, 변화일 활용과 공동 변동 해석의 목적에 따라 [분석 계획](reports/데이터분석_진행계획.md)에서 재검토한다. 현재 진행 중인 수치 분석은 없다.

앞선 [DA-011 A/B 잔여 변동과 발전량 관계](reports/2026-10-21_14_AB잔여변동과_발전량의_관계_분석.md)에서는 같은 80개소의 두 해/두 예보 시각에서 A 운량의 음의 관계와 B UV의 양의 관계가 반복됐다. 날짜/시간 추가 식에서 각 변수의 추가 ΔR²는 A 운량 약 1.13~1.48%p, B UV 약 0.12~0.14%p였다. 큰 잔여 기상 변동과 추가 발전량 설명량을 구분했으며 예측 효용과 인과효과는 미검증이다.

앞선 [DA-007 공동 지지와 날짜 요인](reports/2026-10-21_13_공동지지와_날짜요인의_조건부관계_분석.md)에서 같은 달력 셀의 엄격한 공동 지지는 부족했다. 전체 표본의 선형 운량/습도 음의 관계는 날짜/시간 추가 후에도 반복됐지만 크기는 줄었다. DA-011의 강수 보조 지지는 모든 기상의 공동 지지와 다르며 이 해석 한계를 유지한다.

앞선 [DA-010 장기 관측 표본의 적용 범위](reports/2026-10-21_12_장기관측_표본의_적용범위_분석.md)에서는 관측 길이로 구분한 80/68/105개소의 구성과 비교 가능한 시기를 확인했다. 하반기 80/68/92개소의 제한된 설명식에서 운량/습도의 음의 방향은 반복됐으나 습도 관계의 크기는 집단별 차이가 남았다. 전체 253개소의 연간 유형이나 예보 관계까지 일반화한 결과는 아니다.

앞선 [DA-005 A/B 공통 정보와 잔여 변동](reports/2026-10-21_10_AB예보의_공통정보와_잔여변동_분석.md)에서는 고유 52쌍의 낮 예보에서 첫 두 정준상관이 약 0.90~0.98로 연도 적용에서도 유지됐지만, 두 축의 평균 설명 분산은 A 약 41%/B 약 32%였다. 운량/풍속/강수와 B UV의 선형 잔여 변동을 실제 고유 효용과 구분했으며 예측 성능 개선은 미검증이다.

앞선 [DA-004 시간 구조](reports/2026-10-21_09_발전소_상대수준의_시간구조_분석.md)에서 정한 기준을 통과한 후보를 실제 구조 변화와 발생일의 확정으로 해석하지 않았다. 변화일을 활용할 목적이 생기면 DA-009의 우선순위를 다시 검토한다.

앞선 [DA-002 발전소 곡선 유형](reports/2026-10-21_08_발전소별_발전패턴_유형_분석.md)에서는 공통 80개소의 분기별 정규화 곡선에서 47/33개소의 두 관측 유형 후보가 남았다. 연도/날짜 블록과 제한 기상 조건에서도 구분이 유지됐지만 실제 설비 방향이나 발생 원인은 확정하지 않았다. 연간 형태의 재현이 상대 수준의 모든 시간 구조까지 보장하지는 않는다.

앞선 [DA-001 잠재 구조](reports/2026-10-21_06_기상변수_잠재구조_분석.md)와 [DA-003 조건부 관계](reports/2026-10-21_07_기상조건과_발전량의_조건부관계_분석.md)의 완료 이력과 해석 한계는 유지한다. 전체 변수를 소수 요인으로 대체하는 판단은 보류 상태다.

기존 B3 평가 예측은 중간 후보로 보존한다. [성능 개선 진행 계획](reports/성능개선_진행계획.md)과 아래 모델 비교 결과는 진행 이력이며 현재의 추가 학습이나 예측 실행 지시가 아니다. 데이터 분석 결과를 예측 실험에 연결하는 작업은 사용자의 모델링 재개 지시 후에 진행한다.

현재 우선 참조는 B3다. B5는 기존 연간 비교에서 개선됐지만 후반기 두 분기 각각 개선 기준을 통과하지 못했다. EDA-011 뒤 [H1 교차 특징 비교](reports/2026-10-21_04_H1_운량_태양계절_교차특징_비교.md)를 사전 고정한 4회 적합 예산으로 완료했다. H1은 T0/V1 W가 0.3226%/0.2678% 감소했으나 R3/R4가 1.0200%/0.9358% 증가해 미채택이며 B3를 유지한다.

[EDA 실행 보고서](reports/2026-10-21_03_예보조건별_잔차_EDA.md)에서 흐림의 상대 잔차 대비가 반복됨을 확인하고 [모델링 인계](reports/EDA_개선가설_모델링_인계.md)에 우선 가설 하나를 남겼다. H1에서는 기존 39개 입력과 모델 설정을 유지하고 운량/태양/계절의 교차 특징 3개만 추가했다. 저장 모델/예측을 다시 읽어 점수와 판단을 재현했으며 이 개발 비교가 새 미래 구간이나 공식 제출 성능을 입증하지는 않는다. 기존 선택 3개/보류 5개와 새 선택 EDA-012는 유지하며 별도 EDA를 시작하지 않는다.

[V1 집합 잔차와 라운드 진단](reports/2026-10-20_02_V1_집합잔차와_라운드_진단.md)

[B2 공동 입력의 검증 설계와 비교](reports/2026-10-20_03_B2_공동입력_검증설계와_비교.md)

V1 개발 비교와 추가 과거 재현에서 사전 기준을 통과해 B2를 유망 후보로 유지했다. 다만 전체 253개소의 짧은 연말 표본에서는 악화돼 전체 대상의 개선은 미확인이다. 기존 V2와 EDA 상태는 유지했으며 최종 방법은 확정하지 않았다.

[B2 연말 전체 집합 악화 분해](reports/2026-10-20_04_B2_연말_전체집합_악화분해.md)

같은 178시간에서 기존 148개소와 나머지 105개소의 오차가 모두 증가했고 집단 사이 상쇄도 줄었음을 확인했다. 다음 후보로 B2의 학습 손실만 L1으로 바꾸는 비교를 제안했으며 새 학습과 V2 재평가는 하지 않았다.

[B3 L1 손실 비교](reports/2026-10-20_05_B3_L1손실_비교.md)

B2 대비 V1과 T0의 연간 W가 감소해 사전 개발 기준을 통과한 B3를 우선 후보로 남겼다. 연말 253개소 표본도 개선했지만 짧은 겨울 구간이며 V1 3분기 악화도 남아 있다. V2와 EDA 상태를 보존했고 최종 방법과 제출 성능은 미확정이다.

[B3 최종 학습과 평가 절차 설계](reports/2026-10-20_06_B3_최종학습과_평가절차_설계.md)

B3의 최근 2년 학습 범위와 보수적 마감, 고정 구성 및 출력 검증 절차를 정리하고 253개소의 학습 가용성을 확인했다. 새로운 독립 미래 정답 구간은 확보하지 못했으며 모델 적합, 평가 예측과 제출은 수행하지 않았다.

[B3 여름철 오차 악화 진단](reports/2026-10-20_07_B3_여름철_오차악화_진단.md)

저장된 예측에서 8월 악화가 주로 G1의 가중치 3 시간대 과대예측 비용 증가에 집중됐음을 확인했다. B3 우선 후보를 유지하고 보정 가설은 선택 후보로만 기록했으며 새 학습, 보정 적용과 V2 재평가는 하지 않았다.

[B4 G1 피크 과거 잔차 보정 비교](reports/2026-10-20_08_B4_G1피크_과거잔차_보정비교.md)

과거 순차 검증 잔차에서 추정한 보정안 하나를 비교했다. V1은 개선했지만 T0 연간 W가 악화하고 보정 방향도 불안정해 B4를 채택하지 않고 B3를 유지했다. V2 재평가와 최종 학습/평가 예측 및 제출은 하지 않았다.

[B3 최종 학습과 평가 예측 생성](reports/2026-10-20_09_B3_최종학습과_평가예측_생성.md)

보정 없는 B3를 정한 범위에서 한 번 학습하고 평가 1년의 구성/예측 파일을 로컬에 생성해 검증했다. 전체 253개소와 8,760시간을 유지했으며 평가 정답이 없어 성능 점수는 계산하지 않았다. V2 재평가와 공식 제출은 하지 않았다.

[B5/B6 학습 가중치 비교](reports/2026-10-20_10_B5_B6_학습가중치_비교.md)

용량 가중 L1인 B5가 B3 대비 T0/V1의 연간 W와 분기 안정성 기준을 통과해 초기 개발 우선 후보가 됐다. 가격/시간대 가중을 더한 B6는 T0 악화로 채택하지 않았다. 후속 순차 검증에서 우선 참조를 다시 판단했으며 기존 B3 평가 예측은 중간 후보 산출물로 보존한다.

[B3/B5 후반기 순차 검증](reports/2026-10-20_11_B3_B5_후반기_순차검증.md)

2024년 3분기 224개소와 4분기 252개소에서 각 시점 직전까지 다시 학습해 비교했다. B5는 여름에 개선됐지만 4분기에는 소폭 악화해 사전 기준에 따라 B3를 우선 참조로 되돌렸다. 저장 점수와 판단을 재현했으며 독립 시험이나 제출 성능 확정으로 해석하지 않는다.
