# 초기 분석 방향과 검증 계획

작성일: 2026-10-19 KST. 상태: 논의한 계획 정리. 사용자 확정 및 모델 실행 전이다.

## 목적과 검토 범위

하루전 발전량 예측과 발전소의 두 집합 구성을 어떤 순서로 분석할지 정리한다. 배포 README, 기준선 코드, 기존 데이터 검사 결과와 로컬 설명회 정리를 검토한 뒤 제안한 방향을 기록했다. 이 문서는 이전 논의를 옮긴 것이며 새 실험 결과를 추가한 보고서가 아니다.

## 제안한 분석 순서

1. 발전소별 관측 기간과 결측을 확인해 시계열 검증 구간과 집합 발전 실적을 평가할 수 있는 범위를 정한다.
2. 참조 집합 구성을 유지한 기준선을 과거 검증 구간에서 실행하고 오차를 진단한다.
3. 같은 검증 조건에서 예측 방법을 개선하고 기준선과 비교한다.
4. 발전소별 예측 잔차가 집합 안에서 상쇄되는 정도를 살펴 집합 구성을 개선한다. 예측 개선 효과와 구성 개선 효과를 나눠 비교한다.

가중 집합 절대오차를 기준으로 검증 설계, 기준선 잔차 진단, 예측 개선과 구성 최적화를 순차적으로 살펴보는 방향이다. 실제 점수 계산은 공식 정산식과 대조해 구현해야 한다.

## 검증에서 지킬 조건

- 무작위 분할 대신 예측 시점의 정보 범위를 지키는 시계열 검증을 사용한다.
- 집합 구성 탐색에 쓴 기간과 최종 평가 기간을 분리한다.
- 발전 실적의 빈 행에는 설비 편입 이전과 수집 결측이 섞여 있으므로 0으로 일괄 대체하지 않는다.
- 예측 시점에 사용 가능한 정보와 규정상 허용 범위를 구분한다. 미확정 예외에 기대는 방법은 시작 범위에서 제외한다.
- 기준선 실행 전까지 검증 구간이나 평가 가능한 실적 범위가 확정된 것으로 표현하지 않는다.

## 현재 상태와 한계

계획을 제안한 단계다. 검증 구간 확정, 기준선 학습, 성능 비교, 구성 탐색, 제출 파일 생성 및 공식 제출은 수행하지 않았다. 기존 데이터 품질 확인 결과는 [제공 데이터 확인 결과](../데이터_확인_결과.md)를 참조한다.

다음 분석은 발전소별 관측 기간과 결측을 확인해 검증 구간을 정하는 것이다. 기준선 구현과 실행은 그다음 단계다.
