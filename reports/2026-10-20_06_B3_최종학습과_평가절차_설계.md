# B3 최종 학습과 평가 절차 설계

작성: 2026-10-20T14:20+09:00

상태: 설계와 학습 가용성 점검을 완료했다. 이번 모델 적합, 예측과 성능 계산은 각각 0회이며 공식 제출도 없다. 기본 EDA 종료와 선택 후보 3개/보류 5개를 유지했다.

## 질문과 목적

[B3 비교](2026-10-20_05_B3_L1손실_비교.md)의 후속 설계다. 새 독립 검증을 확보할 수 있는지, 최종 모델이 어느 시점까지의 자료로 학습할지, 예측 파일을 어떻게 검사할지 정했다. B3는 개발 우선 후보이며 이번 문서만으로 최종 성능을 확정하지 않는다.

결정한 후속 실행안은 **B3의 특징과 설정을 고정해 한 번 학습하고, 참조 구성 그대로 평가 1년의 예측 파일을 로컬에서 생성하는 것**이다. 다른 학습 기간, 새 모델, 가중치, 편향 보정이나 구성 탐색은 이 실행안에 넣지 않았다. 실제 학습과 파일 생성은 아직 하지 않았다.

## 사용 범위와 수행 방법

기존 [검증 설계](2026-10-19_18_검증과_데이터처리_설계.md), [S0 점검](2026-10-19_19_S0_구현_점검.md), B3 보고서 및 로컬 배포 README/기준선 코드를 검토했다. 제공 자료와 기존 요약을 바탕으로 설계했으며 최신 공식 규정을 새로 조회한 작업은 아니다.

실행 점검은 원본 발전량의 키와 시간, 학습 가능 행 수, 메타 구성과 평가 시간축에 제한했다. 학습 시작과 마감은 점검 전에 이 문서에 적고 로컬 사본으로 보존했다. 예보 값의 새 분포 탐색, 새로운 오차 계산이나 독립 EDA는 하지 않았다.

B3의 확인된 근거는 개발 표본에서 B2 대비 V1 연간 W 1.5006%, T0 5.1366% 감소와 연말 253개소 178시간에서 15.4667% 감소다. V1 3분기 2.4389%, 8월 7.8283% 악화와 짧은 전체 집합 표본의 한계도 함께 유지한다. 이 값을 평가 1년의 예상 성능으로 옮겨 쓰지 않는다.

## 최종 학습 범위와 시점

모든 경계는 KST다. 대상 날짜는 s=ts-1시간으로 정하며, 모델은 첫 대상일 전에 한 번 학습한 뒤 평가 1년 동안 고정한다.

| 항목 | 정한 값 |
|---|---|
| 학습 구간 시작 s | 2023-06-01 00:00 이상 |
| 학습 목표 ts 상한 | 2025-05-31 00:00 이하 |
| 실제 선택된 ts | 2023-06-01 01:00~2025-05-31 00:00 |
| 첫 예측 시점 | 2025-05-31 17:00 |
| 평가 대상 s | 2025-06-01 00:00 이상, 2026-06-01 00:00 미만 |
| 평가 종료 시각 ts | 2025-06-01 01:00~2026-06-01 00:00, 8,760시간 |

시작은 배포 기준선의 최근 2년 범위와 기존 V1의 약 2년 학습 정책을 따른다. 마감은 기존 설계의 보수적 규칙인 첫 대상일의 전날 00시로 유지했다. 최근 1년이나 3년보다 유리하다고 확인한 선택은 아니며, 기간별 성능 탐색은 하지 않았다.

마감은 첫 예측 시점보다 17시간 앞선다. 제공된 발전량 중 마감 이후 6,072행을 제외해, 대상 시작 전이라는 이유로 5월 31일의 늦은 실적까지 넣지 않았다. 이 마감은 실제 수신 지연을 검증한 결과가 아닌 기존 보수적 정책이다.

최종 학습에는 이전 V2 기간에 해당하는 실적 910,800행이 포함된다. 모델 선택이 끝난 뒤 첫 평가 예측 시점 이전의 관측을 최종 적합에 쓰는 것이며, V2를 재채점해 B3와 B0/B2를 다시 고르는 절차와 구분한다. 평가 기간의 발전량은 학습하지 않으며 이후 일별 정답 갱신도 하지 않는다.

## 고정할 모델과 데이터 처리

| 항목 | 후속 실행 계약 |
|---|---|
| 모델 수와 손실 | 단일 LightGBM, objective=regression_l1, 최종 적합 1회 |
| 특징 | 라운드 10/17의 기상 각 15개와 태양/달력/메타 9개, 총 39개. B3의 순서와 float32 자료형을 유지한다. |
| 기압 | 두 라운드의 wa_ground_press를 유지한다. 새 제외/보정 실험은 없다. |

| 예보와 특징 조인 | 각 대상 날짜 전일 10/17시 예보를 정확한 정시 키로 왼쪽 조인한다. 결손은 NaN으로 유지하고 예측 격자를 삭제하지 않는다. |

현재 B3의 저장된 파라미터 및 39개 특징 순서를 대조했다. 최종 모델은 기존 V1/T0 모델을 그대로 사용하는 대신 정한 최종 범위에서 새로 적합해야 한다. 단일 공동 입력 모델이므로 두 라운드 모델을 따로 만들거나 출력 평균을 새로 적용하지 않는다.

학습 기간이 달라지고 253개소가 모두 학습에 들어오는 조건은 기존 개발 비교와 차이가 있다. 이 변화의 성능을 별도로 확인한 것은 아니다. 기본 난수 설정 유지와 재현용 파일/환경 기록은 구분하며 다른 환경에서 비트 단위 결과가 같다고 보장하지 않는다.

## 고정 구성과 출력 규격

구성 최적화는 포함하지 않는다. current_group A를 G1, B를 G2로 대응시키고 평가 1년 동안 유지한다.

| 집합 | 발전소 수 | 정확한 설비용량 |
|---|---:|---:|
| G1 | 134 | 20,465.655 kW |
| G2 | 119 | 22,189.715 kW |
| 전체 | 253 | 42,655.370 kW |

각 집합 20,000 kW 이상, 모든 발전소의 누락/중복 없는 배정을 만족함을 다시 확인했다. 소수 첫째 자리로 반올림한 안내 수치로 유효성을 판단하지 않는다.

| 예정 로컬 파일 | 열과 데이터 행 수 | 후속 생성 시 확인할 항목 |
|---|---|---|
| composition.csv | site_id, group / 253행 | 원본 site_id 집합과 일치, 각 ID 1회, G1/G2만 사용, 용량 조건 |
| forecast.csv | group, ts, forecast_kwh / 17,520행 | 집합별 smp.csv의 8,760시각과 정확히 일치, KST 타임존, 키 유일, 모든 값 유한/비음수 |
| 발전소별 예측 Parquet | site_id, ts, kwh / 2,216,280행 | 253×8,760 전체 격자, 누락/중복 없음, 집합 합계와 보존 일치 |
| 모델과 실행 manifest | UTF-8 모델 문자열, JSON | 실제 실행 코드/입력/설계/특징/설정/환경과 출력 해시, 적합 횟수, 종료 상태 |

집합 예측은 발전소별 kWh를 구성별로 합산한다. CSV는 UTF-8 BOM을 사용하고 ts는 +09:00이 있는 문자열로 저장한 뒤 다시 읽어 검사한다. 내부적으로 10/17 라운드를 함께 쓰더라도 제출값은 집합과 시각마다 하나다.

SMP=0인 18시간도 출력에서 유지한다. 제공 k가 KST 종료 11~15시에 3, 나머지에 1인 규칙과 일치함을 확인했다. SMP/k는 이번 모델의 입력이나 새로운 가중 학습에 사용하지 않는다.

평가 격자의 예보 조인은 이번에 새로 실행하지 않았다. 원본 해시가 같은 [S0](2026-10-19_19_S0_구현_점검.md)의 라운드별 2,216,280행 검사 결과만 참고했다. 실제 B3 공동 입력의 조인/행 수, 두 라운드 키와 공통 특징 일치, NaN/무한값 검사는 생성 단계에서 실행해야 한다.

## 후속 실행 순서와 중단 조건

1. 현재 설계와 원본, B3 설정, 코드 및 실행 환경을 확인하고 고유한 Git 제외 출력 경로를 만든다. 완료 산출물을 덮어쓰지 않는다. 설정/입력 변경이 필요하면 이유를 기록하고 변경된 실행으로 구분한다.
2. 정한 관측 학습 행을 조인해 B3 공동 특징과 낮 행 수를 검사한다. 실제 값과 행 수가 계약에 맞는지 확인한 뒤 모델을 1회 적합하고 즉시 저장한다. 한글 경로에서는 model_to_string과 Python UTF-8 파일 쓰기를 사용한다.
3. 같은 고정 모델로 평가 1년을 월 단위로 예측하고 전체 발전소 격자를 보존한다. 구성과 예측 파일을 생성해 저장 파일을 다시 읽고 위 표의 기준 및 발전소/집합 합계 일치를 확인한다.
4. 정상 종료와 해시를 기록하고 중간보고서를 만든다. 원본 데이터, 예측/모델/집계 파일은 로컬에만 두고 공개 가능한 코드와 보고서/로그만 로컬 커밋한다.

키 중복, 잘못된 시간 경계, 조인 행 변화, 목표값 누출, 특징 순서 변화, 무한 예측, 출력 누락과 구성 용량 위반은 중단 조건이다. 예보 NaN은 기존 모델 처리 범위이며 행 삭제나 자동 0 대체의 근거가 아니다. 저장된 모델로 이어갈 수 있는 출력 오류는 모델을 다시 적합하지 않고 고친다. 불가피한 재적합이 생기면 사유와 실제 횟수를 기록한다.

실행 예산은 B3 최종 모델 1회, 다른 기간 비교 0회, 추가 후보 0회다. 기존 V2 모델/예측/점수의 재계산은 없다. 실제 생성 과정이 완료돼도 공식 제출이 자동 실행되는 것은 아니다.

## 성능 평가와 해석의 경계

대회 목표는 정산금 S이며 같은 구성/정답에서는 W 감소가 유리하다. W는 집합별로 합친 잔차의 절댓값에 SMP×k를 곱해 합산한다. 개별 MAE나 G1/G2를 합친 하나의 잔차로 대체하지 않는다.

이번 최종 평가 기간에는 발전량 정답이 없어 W, S_local, 가중 집합 MAE와 개별 MAE를 계산할 수 없다. 출력 파일이 유효하다는 검사는 예측 성능 검증과 별개다. 학습 오차를 새 일반화 성능으로 제시하거나, 평가 예보의 분포와 예측 분포를 근거로 후보를 다시 고르지 않는다.

공식 점수를 확인하는 단계가 생기면 이번 로컬 개발 결과와 별도 기록한다. 현재 폴더에는 공식 scoring.py와 문제정의서가 없어 공식 채점기와의 동치가 확인되지 않았다. 실제 제출 전에는 최신 정본의 파일 규격과 제출 절차를 확인해야 한다. 이 확인은 이번에 수행하지 않았고 로컬 학습 가능성과는 구분한다.

평가 예보의 기압 변화, 짧은 전체 집합 검증, 여름 일부 악화와 난수 반복 미실행의 한계는 남는다. 이번 설계로 그 문제가 해결됐다고 보지 않는다. 실측 기상이나 평가 정답을 외부에서 가져오지 않으며 EDA 보류 질문을 자동 재개하지 않는다.

정규 CPython 3.13.1에서 2026-10-20T14:19+09:00~14:20+09:00에 가용성 코드를 실행해 종료 코드 0으로 완료했다. 최초 실행은 요약 생성부의 괄호 구문 오류로 데이터 읽기 전에 종료했고, 수정 후 위 점검을 완료했다. 모델 적합과 예측은 두 실행 모두 0회다.
