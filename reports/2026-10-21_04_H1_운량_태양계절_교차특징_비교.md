## 질문과 EDA 근거

[EDA-011 실행 결과](2026-10-21_03_예보조건별_잔차_EDA.md)와 [모델링 인계](EDA_개선가설_모델링_인계.md)의 H1 하나만 시험한다. 같은 월/시각/태양고도 셀에서 흐림의 B3 잔차가 나머지 조건보다 낮은 상대 대비는 R3/R4와 한 차례 T0/V1 재확인, 기존/추가 표본에서 반복됐다. 절대 과대/과소 방향은 달랐으므로 고정 잔차 보정을 하지 않는다. 이미 본 개발 자료의 관찰이며 성능 개선이나 인과 효과의 확인은 아니다.

현재 B3의 입력과 모델 설정을 유지하고 교차 특징 3개만 추가하면 전체 집합 W가 줄어드는지 묻는다. 전처리, 가중치, 손실, 모델 용량과 정규화를 함께 바꾸거나 다른 가설을 시험하지 않는다.

## 특징과 예측 시점 가용성

기존 공동 입력 39개는 A/B의 10시/17시 기상 30개와 태양/달력/메타 9개다. `wa_ground_press_r10/r17` 두 기압 열을 포함한 원래 순서/float32/NaN 처리를 유지한다. 다음 세 열을 순서대로 붙여 총 42개로 만든다.

```text
A = 기존 float32 wa_cloud_r17을 float64로 변환
B = 기존 float32 wb_cloud_r17을 float64로 변환
m = (A+B)/200
z = max(기존 cosz, 0)
s = 기존 doy_sin = sin(2*pi*dayofyear(KST ts)/365.25)
c = 기존 doy_cos = cos(2*pi*dayofyear(KST ts)/365.25)

cloud_solar     = float32(m*z)
cloud_solar_sin = float32(m*z*s)
cloud_solar_cos = float32(m*z*c)
```

입력 운량은 %, m과 세 추가 특징은 무차원이다. 곱셈 중간 계산은 float64, 최종 열은 float32다. z/s/c는 기존 B3 float32 값에서 변환해 계산하며 태양기하를 새 방식으로 추정하지 않는다. 원래 cosz는 시간 구간 중앙의 태양 천정각 코사인이고 dayofyear는 기존 종료 시각 ts 기준이다.

A 또는 B가 NaN/비유한/0~100 범위 밖이면 추가 3개만 NaN으로 둔다. 한 제공사의 값이나 평균/0으로 대체하지 않는다. 원래 39개 열과 행은 유지한다. B3의 원시 특징 유한성 검사도 유지하므로 원래 inf가 있으면 기존 계약대로 중단한다. cosz/달력 특징이 비유한이면 중단한다. 사후 EDA의 운량 80%나 태양고도 15도 경계를 새 입력의 문턱이나 학습 행 필터로 사용하지 않는다.

전날 17시 발행 예보, 정적 위경도와 이미 알려진 대상 시각만 필요하므로 하루전 예측 시점에 계산할 수 있다. 대상일 실측/관측 발전량/미래 잔차는 사용하지 않는다. 특징의 평균/분위수/정규화 계수와 보정계수는 적합하지 않으며 학습 전체 또는 검증 전체의 잔차 평균도 쓰지 않는다. 모델만 각 구간 학습 마감 이전 자료에서 적합한다.

## 시간과 고정 표본

s는 KST ts-1시간이고 cutoff는 ts 기준 00:00 포함이다. 학습 마감이 최초 예측 시점보다 앞서는지 코드에서 검사한다. 원본 발전량 결측을 0으로 채우지 않고 고정 표본의 정답 완전성을 재확인한다.

| 구간 | 대상일 | 학습 s 시작 이상 | 학습 ts 마감 이하 | 고정 표본 |
|---|---|---|---|---|
| T0 | 2023년 | 2022-01-01 | 2022-12-31 00:00 | 기존 80개소 |
| V1 | 2024년 | 2022-01-01 | 2023-12-31 00:00 | 기존 148개소 |
| R3 | 2024년 3분기 | 2022-07-01 | 2024-06-30 00:00 | 기존 완전 224개소 |
| R4 | 2024년 4분기 | 2022-10-01 | 2024-09-30 00:00 | 기존 완전 252개소 |

표본 ID는 T0/V1의 기존 B2 precheck와 R3/R4의 availability에 고정된 값을 재사용한다. 예측은 각 구간 253개소 전체 격자에 저장하고 주 판단은 위 표본의 같은 시각/가격/참조 그룹에서 계산한다. 전체 253개소의 공통 정답은 별도 짧은 진단으로만 남기며 연간 표본과 합치지 않는다. V1과 R3/R4의 정답은 겹치므로 독립 시험이라고 부르지 않는다.

## 참조 계약과 적합 예산

참조 B3 저장 모델/예측의 해시, 39개 특징 순서/자료형, L1/600개 트리, 학습 행/낮 행/NaN 행 수, 학습 첫/끝 시각을 현재 입력으로 다시 대조한다. 정규 Python/LightGBM/NumPy/pandas/pyarrow 버전도 기존 실행과 비교한다. 같을 때만 저장 B3를 재사용한다. 원본과 EDA 코드/출력/보고서/검증 해시는 precheck에 보존한다.

B3와 H1 모두 objective=regression_l1, n_estimators=600, learning_rate=0.06, num_leaves=127, min_child_samples=200, subsample=0.8, subsample_freq=1, colsample_bytree=0.8, verbose=-1, n_jobs=-1을 쓴다. 기존 random_state=None 동작과 동일 비중 학습을 유지한다. 조기 종료, 난수/설정 탐색과 sample_weight 추가는 하지 않는다.

학습 목표는 기존 `clip(energy/float32 cap,0,1.2)`, 학습 행은 기존 태양고도 >0이다. 예측은 야간과 음수를 0으로 만들고 용량을 곱하며 상한을 적용하지 않는다. 채점 정답은 자르지 않는다. LightGBM 모델은 문자열 저장/로드 방식으로 한글 경로의 네이티브 파일 접근을 피한다.

기본 예산은 T0/V1/R3/R4 각 1회, 총 4회다. 참조 재학습은 하지 않는다. 참조 계약이 다르면 학습 전에 중단해 이유를 기록하며 자동으로 예산을 늘리지 않는다. 이번에는 최대 8회 예외를 예약하지 않는다. 모든 구간을 결과와 관계없이 실행하며, 점수를 본 뒤 표본/기간/예산/기준을 바꾸지 않는다. fit_journal이 있는 부분 실패는 자동 재적합하지 않으며 완료 모델/예측은 재사용한다.

## 고정 채택 기준과 평가

주 지표는 `W=Σ(g,t)SMP(t)k(t)|Σ(i∈g)(prediction-actual)|`다. k는 KST 종료 시각 11~15시에 3, 나머지는 1이다. G1/G2 잔차를 먼저 상쇄하지 않는다. 같은 정답과 구성에서 R은 같고 S=R-0.10W이므로 W가 낮을수록 좋다.

네 조건을 모두 만족해야 H1을 채택한다. 개선/한도 비교에는 rtol=1e-12, atol=0의 동률 판정을 사용한다.

1. T0와 V1 연간 W가 각각 엄격히 감소한다.
2. 두 연간 표본에서 어느 분기도 W가 5% 초과 악화하지 않는다.
3. R3와 R4 분기 W가 각각 엄격히 감소한다.
4. R3/R4의 어느 월도 W가 5% 초과 악화하지 않는다.

전체/월/분기/k, G1/G2와 기존/추가 표본, 과대/과소 비용, EDA에서 고정한 8개 조건 및 흐림 공유 셀 대비를 함께 기록한다. 조건별 W는 같은 집합-시각 분할로 합계를 보존한다. 기존/추가 소집합의 내부 W는 합산하지 않으며 전체 부호를 쓴 기여를 별도로 기록한다. 조건 일부만 좋아지고 전체 계약을 통과하지 못하면 B3를 유지한다.

추가 특징의 산술/결측/자료형/배치 독립성, 시간 누출 거부, 5% 한도/동률과 표본 변경 거부를 합성 테스트한다. 현재 학습 계약을 B3와 대조한 뒤 코드/입력/사전 보고서/계획을 고정한다. 학습 후 저장한 네 모델의 L1/트리/42개 순서, 예측 키/전체 격자/유한/비음수/해시를 다시 읽어 검사하고 같은 정답으로 W와 판단을 재현한다. 월/분기/k/집합 및 조건/방향 비용 합을 검증한다.

T0/V1/R3/R4는 이미 관찰한 개발 자료이며 V1과 R3/R4는 정답 기간이 겹친다. 완전 관측 표본 선택, 짧은 전체 253개소 공통 구간과 단일 적합, 같은 날/지역의 의존성과 공식 채점 구현 동치 미확인 한계를 유지한다. 특징 3개는 새 관측 정보가 아니라 기존 입력의 표현 변경이며 일반화나 원인을 증명하지 않는다.
