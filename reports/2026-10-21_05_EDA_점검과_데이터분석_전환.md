# EDA 점검과 데이터 분석 전환

작성: 2026-10-21 KST. 상태: 기존 문서 검토와 분석 방향 정리 완료. 새 통계 분석은 미실행.

## 질문과 목적

기존 EDA가 데이터 이해에 충분했는지 확인하고, 사용자가 요청한 데이터 자체의 분석과 이후의 예측 성능 실험을 구분한다. 사용자는 FA를 예시로 들며 여러 분석을 통해 데이터를 이해한 뒤 얻은 인사이트를 모델링에 활용할 수 있다고 설명했다.

## 사용 범위와 수행 방법

[EDA 종합](2026-10-19_10_EDA_종합과_남은_판단.md), [변수 관계 보고서](2026-10-19_09_기상_변수_사이의_관계_EDA.md), [EDA 계획](EDA_진행계획.md), [성능 계획](성능개선_진행계획.md), 최신 로그와 인계 문서를 읽었다. 문서에 기재된 실행 이력과 해석 범위를 검토했으며 과거 계산을 이번 작업에서 재실행하거나 독립 검증하지 않았다. 데이터 원본은 열거나 수정하지 않았다.

## 결과

### 기본 EDA는 폭넓게 했지만 데이터 구조의 설명은 남아 있다

기존 EDA는 분포와 품질, 발전량과 기상 관계, 시간과 공간, 예보/실측과 A/B 자료, 기간별 차이까지 다뤘다. 따라서 기초 탐색이 거의 없었다고 볼 근거는 없다. 반면 그 완료 판단은 당시 정한 기본 범위의 종료이며 충분한 잠재 구조 설명과 다변량 관계 검증을 마쳤다는 뜻은 아니다.

| 기존 확인 수준 | 아직 검증하지 않은 데이터 질문 |
|---|---|
| 기상 변수의 전체/낮/그룹 내 쌍별 상관과 중복 정보 후보 | 여러 변수의 공통 변동을 소수 요인으로 설명할 수 있는지, 그 구조가 기간을 넘어 유지되는지 |
| 발전소 쌍의 동시 변동과 현재 그룹 구성 | 데이터에서 구분할 수 있는 발전소 유형이 있는지, 같은 날씨에 대한 반응도 다른지 |
| 월/시간/지점 평균을 뺀 관계와 조건별 비교 | 여러 변수를 함께 고려한 조건부 관계의 형태와 불확실성 |
| 시차와 저발전 지속, 기간별 분포와 특정 기압 변화 시점 | 계절성과 구성 변화를 고려한 발전량/기상 관계 구조의 변화 |
| A/B 같은 변수의 일치, 차이와 쌍별 상관 | 두 자료의 다변량 공통 구조와 고유 변동 |

최근 EDA-011은 저장 모델 잔차로 개선 가설을 만들었고, P-005는 그 특징을 시험했다. 이 흐름은 예측 오차 개선에 집중했으며 사용자가 이번에 설명한 데이터 자체의 심화 분석을 대신하지 못한다.

### 현재 성능만으로 원인을 단정할 수 없다

기존 EDA의 범위가 넓다는 사실로 성능 향상에 필요한 이해가 충분하다고 할 수 없다. 반대로 최근 모델 실험의 개선이 작거나 불안정하다는 이유만으로 EDA 부족이 원인이라고 결론 내릴 수도 없다. 잠재 구조나 조건별 관계를 새로 분석해도 예측 성능이 반드시 개선되는 것은 아니다. 이번에는 데이터에 대한 결론과 그 재현성을 분석의 직접 성과로 삼는다.

### 데이터 분석을 별도 단계로 관리한다

[데이터 분석 진행 계획](데이터분석_진행계획.md)에 다섯 질문을 후보로 등록했다. 첫 순서는 기상 변수의 잠재 구조 분석에 앞선 적용 가능성 점검이다. 기존 보고서에서 동일 열, 거의 중복인 열과 조건에 따라 다른 상관이 확인됐기 때문에 이들을 구분한 표본과 변수 구성이 필요하다. FA가 적합하지 않거나 구조가 불안정하면 그 이유도 결과로 남긴다.

FA는 사용자의 예시이며 이번에 실행이 확정된 단일 기법으로 취급하지 않는다. 탐색적 요인분석처럼 탐색 목적의 통계 방법도 있으므로 EDA와 분석의 명칭을 엄격히 나누기보다 이번 작업의 목적과 검증 깊이를 명확히 한다.

## 한계와 다음 단계

이번에 완료한 것은 문서 검토, 질문 등록과 작업 범위 변경이다. FA, 군집, 설명 목적의 회귀나 변화점 분석은 아직 실행하지 않았다. 설치 패키지 확인, 코드 작성, 원본 재집계와 그림 검토도 수행하지 않았다.

다음 작업에서는 DA-001의 실제 자료 가용성과 방법 적합성을 확인하고 변수, 기간, 표본과 종료 기준을 독립 보고서에 고정한 뒤 계산한다. 발전량 예측 실험은 현재 중단하며 사용자의 재개 지시 전에는 분석 결과를 학습/튜닝/추론으로 연결하지 않는다. 과거 모델과 평가 예측은 보존한다.
