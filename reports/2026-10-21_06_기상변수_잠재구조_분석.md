# 기상 변수의 잠재 구조 분석

작성: 2026-10-21 KST. 상태: DA-001 완료. 아래 계약은 상관/요인 계산 전에 고정했으며 변경 없이 실행했다.

## 질문과 목적

여러 기상 변수의 공통 변동을 소수의 구조로 설명할 수 있는지, 그 구조가 달력 구성을 고려한 뒤에도 남고 다른 기간에도 유지되는지 확인한다. 발전량 예측과 모델 성능 실험은 수행하지 않는다.

## 사용 범위와 수행 방법

제공 학습 기상 자료를 A/B, 실측/10시 예보/17시 예보로 나눠 확인한다. 2024년 완전 관측 발전소와 연결된 고유 기상 지점을 시작 표본으로 두며 실제 가용성 점검 뒤 2023년 재현 범위를 고정한다. V2와 제공 평가 자료는 사용하지 않는다.

### 계산 전에 고정한 계약

- 실행 환경 확인 결과는 정규 CPython 3.13.1, numpy 2.2.6, pandas 3.0.1, scipy 1.17.1, statsmodels 0.14.6이다. A 40개, B 47개 지점의 2023/2024 자료가 모두 있다. 이 확인 단계에서는 상관과 요인을 계산하지 않았다.
- A의 주 변수는 기온, 습도, 운량, 지표기압, 풍속, 강우량과 강설량 7개다. 동일/유사한 최대/최저기온과 원형 풍향은 제외한다. B는 기온, 상대습도, 운량, 풍속, UV, 강우량(실측은 1시간 강수량), 시정과 운고 8개다. 파생 체감온도, 이슬점, 확률, 거의 중복된 총 강수량과 눈/착빙 계열을 동시에 넣지 않는다. 이 선택은 분석용이며 원본 또는 모델 입력의 최종 변수 선택이 아니다.
- 강우량, 강설량과 운고에 log1p를 적용한다. 단위가 다른 A/B 수치를 합치지 않는다. B 예보 강우량과 실측 1시간 강수량의 정의가 같다고 전제하지 않는다.
- 기존 EDA의 비교 범위를 재사용한다. 습도/운량은 0~100, A 풍속 0~50 m/s, B 풍속 0~200 km/h, A 기압 900~1100 hPa, B UV 0~15, 시정 0~50 km, 강우/강설/운고는 0 이상이다. 범위 밖/비유한 셀은 분석용 결측으로 두며 대치하지 않는다. B 집중값의 의미는 미확정으로 보존한다.
- ts는 구간 종료다. 한 시간을 뺀 KST의 연도와 날짜를 사용하며 비정시를 제외한다. 실측 중복 키는 변수별로 값이 일치하면 한 값, 충돌하면 NaN인 임시 뷰를 만든다. 예보는 라운드를 나눠 키 중복이 없어야 한다.
- 기상 지점은 2024년 완전 관측 148개 발전소에 연결된 고유 지점으로 고정한다. 지점별 반복 가중을 같게 만들기 위해 선택 변수 전체가 모든 고정 지점/24시간에 유효한 날짜만 남긴다. 제외 전후 행/날짜와 이유를 집계한다. 2023년도 동일 규칙이다. 어느 달의 잔존 날짜가 14일 미만이면 해당 자료 전체의 주 분석을 보류한다.
- 각 자료/연도에 두 뷰를 만든다. 전체 24시간 수준과 구간 시작 9~16시의 같은 지점/월/시간 평균을 뺀 편차다. 편차 평균은 해당 연도 안에서만 계산한다. 이것은 계절/일변화의 비교용 제거이며 완전한 교란 통제나 예측 전처리가 아니다.
- 상관행렬의 최소 고유값 1e-8 초과, 조건수 1e8 미만, 비상수와 유한성을 확인한다. KMO 전체/변수별 값을 보고하되 낮아도 탐색적 결과를 숨기지 않는다. 전체 KMO 0.6 미만이면 공통요인 적합성이 약하다고 표시한다. 독립 행을 전제한 Bartlett p값은 계산하지 않는다.
- 요인 수는 2024년에서 고정한다. 각 변수의 날짜 순서를 같은 달 안에서 독립 순환이동하되 모든 지점과 시간은 함께 이동해 변수별 공간 구조와 일중 패턴을 보존한다. 199회, seed 20261021의 귀무 상관행렬 고유값별 95백분위보다 관측 고유값이 큰 차원 수를 센다. 이는 계절/일변화를 남기는 맞춤 기준이며 표준 iid 평행분석이나 유의확률로 표현하지 않는다. 상관은 FFT로 계산한 순환이동 교차곱으로 재현하고 합성 자료에서 직접 이동과 동치를 검증한다.
- 주축요인법(PA), varimax 회전, 최대 500회와 tol 1e-8을 사용한다. 주 요인 수는 위의 차원 수를 1~3과 양의 자유도를 만족하는 범위로 제한한다. 차원 수 0이면 FA를 강제하지 않는다. 선택 수가 상한을 넘으면 제한 사실을 적는다. 부적절해, 수렴 경고, 공통성과 독자성 범위를 점검하며 실패는 누락하지 않는다. PCA 2개와 3개의 누적 전체 분산 비율은 별도 비교로 보고한다.
- 2024년의 같은 요인 수로 2023년과 각 2024년 분기에 재적합해 구조를 비교한다. 분기 내 상수 변수나 부적절한 행렬로 적합할 수 없으면 그 이유를 보고하고 변수를 사후 제거해 성공시키지 않는다. 이 재적합은 기간별 기술 분석이며 독립 미래 예측 검증이 아니다.
- 2024년 날짜를 7일 이동블록으로 재표집하는 부트스트랩을 100회 한다. 한 날짜의 모든 지점/시간/변수를 함께 추출하고, 편차 뷰의 달력 평균은 고정한 조건부 재표집으로 다룬다. 회전 요인을 절대 Tucker 일치도가 최대인 순열과 부호로 맞춘 뒤 일치도와 적재량 95% 백분위 구간을 저장한다. 실패 비율도 공개한다. 시간/공간 의존성을 고려한 기술적 안정성 점검이며 엄밀한 모수 신뢰구간으로 일반화하지 않는다.
- 2023년 요인 일치도 최솟값 0.85 이상, 2024년 블록 일치도 최솟값의 5백분위 0.85 이상, 잔차 상관 RMS 0.10 이하이면 이 표본에서의 안정적 요약 후보로 표시한다. 이는 이번 작업의 기술적 기준이다. 블록 적합 성공률 90% 미만, KMO 0.6 미만, 요인당 절대 적재량 0.4 이상인 변수가 2개 미만이면 추가 경고를 붙인다. 하나의 지표만으로 구조를 확정하지 않는다.
- B의 집중값 영향을 변수 선택과 구분하려고 같은 행에서 시정/운고 두 열을 제외하는 민감도를 한 번 수행한다. 같은 절차로 2024년 요인 수와 적합성을 계산하고 2023년에서 재현을 확인한다. 집중값이 있는 행을 삭제하지 않으므로 이 비교는 집중값 제거 효과 자체의 검증이 아니다. 추가 독립 질문은 후보로만 기록한다.
- 종료 기준은 6개 자료/두 뷰의 적합성, 요인 수, 적재량, 재현 잔차, 기간/블록 안정성 및 B의 변수군 민감도를 확인하고 지지되는 구조와 한계를 구분하는 것이다. 발전량 예측, 특징 추가 실험, 튜닝, V2/평가 구간 분석과 제출은 0회로 유지한다.

### A에서는 이번 3요인 해를 해석할 수 없다

A의 KMO는 전체 수준에서 0.512~0.521, 낮 편차에서 0.546~0.562로 사전 주의 기준 0.6보다 낮았다. 귀무 비교에서는 세 차원이 선택됐지만 여섯 해 모두 공통성이 1을 넘는 변수가 나타났고 수렴 검사도 통과하지 못했다. 이는 독자성이 음수가 되는 부적절해다. 잔차 상관이 작더라도 이를 유효한 잠재 요인으로 채택할 수 없다.

이번 변수 구성과 정한 요인 수에서 안정적인 해를 얻지 못했다는 결론이다. A의 모든 변수 사이에 공통 정보가 없다거나 더 적은 요인이나 다른 추정 방법도 실패한다는 결론은 아니다. A를 임의로 몇 개 요인으로 치환하는 대신 공통 변동과 고유 변동을 구분할 추가 검토 후보를 DA-006에 남긴다.

B 17시 예보의 낮 편차 첫 축은 UV +0.808, 운량 -0.769, 습도 -0.520이 함께 나타났다. 운고 +0.767과 시정 +0.434도 같은 축에 걸렸다. 달력 평균을 제거한 뒤에도 맑음/흐림에 동반하는 공통 변동이 남은 셈이다. 이를 실제 일사량이나 구름의 인과 효과를 측정한 요인으로 확정하지는 않는다.

이 첫 축의 2023년 Tucker 일치도는 10시 0.982, 17시 0.984였다. 반면 두 번째 축은 각각 0.432와 0.379였다. 두 번째 축에서 절대 적재량 0.4 이상인 변수도 기온 하나뿐이었다. 기온에 가까운 이 축을 다른 변수까지 함께 설명하는 안정적인 공통요인으로 해석할 근거가 약하다.

17시 예보 낮 편차에서 강우량의 공통성은 0.156, 풍속은 0.106이었다. 정한 두 요인이 이 변수들의 표준화된 변동 중 약 15.6%와 10.6%만 재현했다는 뜻이다. 운량/UV 축이 뚜렷하다는 이유로 강수나 바람을 같은 축으로 대체하면 관측된 별도 변동을 많이 잃을 수 있다. 이것이 그 변동의 발전량 예측 유용성을 입증한 것은 아니다.

블록 부트스트랩은 세 뷰에서 각 100회, 총 300회 시도했다. 실패한 적합은 구간 계산에서 제외하고 실패율을 별도로 보고했다. 따라서 성공 표본에서의 높은 일치도만 보고 전체 추정이 안정적이라고 결론 내릴 수 없다. 두 예보의 첫 축은 성공 재표집에서 높은 일치도를 보였지만 두 번째 축의 불안정성과 적합 실패를 함께 남긴다.

B 실측 전체 수준의 두 요인은 2023년 재현과 잔차/블록 일치도 수치 기준을 통과했다. 다만 블록 성공은 81%로 정한 90% 경고 기준에 미달했고 두 번째 축의 4분기 일치도는 0.793이었다. 연간 전체 수준의 비교적 재현되는 요약 후보이며 모든 계절에 안정적인 구조로 확정하지 않는다.

B 실측 낮 편차는 500회 반복 후 다음 공통성 갱신의 차이가 약 2.11e-5로 허용값 1e-6을 초과했다. 이 해를 적정 해로 보고하거나 반복 상한을 사후 늘려 성공 결과로 바꾸지 않았다.

모든 민감도는 같은 날짜와 행에서 두 열만 제외했다. 특정 집중값 행의 포함/제외 효과를 분리한 분석은 아니며 그 값이 결측 코드라는 결론이나 해당 행의 삭제 권고를 내리지 않는다.

## 한계 및 다음 단계

주축요인법과 직교 varimax, 정한 변수군에 한정된 결과다. 선형 공통요인으로 설명하기 어려운 비선형 관계, 강수/강설의 0 집중과 희소성, 상관된 요인의 가능성은 남는다. 부적절해나 미수렴을 데이터 오류 또는 잠재 구조 부재로 단정하지 않는다. 이번에는 사후 방법 교체와 요인 수 탐색을 이어가지 않았다.

월 안의 날짜 순환이동은 공간과 일중 구조를 보존하지만 월 경계 및 이동 경계의 시간 연속성은 바뀐다. 또한 유한 199회 기준에 가까운 고유값의 차원 수는 불안정할 수 있다. 7일 재표집도 관측 가능한 균형 날짜 순서를 기준으로 해 제외 날짜를 지나는 블록에서는 정확한 달력 7일이 아니다. 고정 지점 모집단과 이미 계산한 달력 평균에 조건부인 기술적 결과이며 모든 지점과 미래 연도에 대한 확증적 검정으로 일반화하지 않는다.

DA-001은 정한 범위에서 종료한다. 전체 기상 정보를 소수 요인으로 대체하는 판단은 보류한다. 다음 우선 후보는 DA-003이다. 반복된 맑음/흐림 공통 변동과 그 축으로 설명되지 않은 강수/바람을 함께 고려했을 때 발전량의 관계가 어떻게 다른지 설명 목적의 다변량 분석으로 다룰 수 있다. 실제 표본, 방법과 종료 기준은 시작 전에 별도로 고정한다. A의 더 적은 요인/변수군 검토는 DA-006 선택 후보로 남긴다.

모델링 활용은 가설 단계다. 공통 축의 조건부 표현과 개별 변수의 남는 정보를 구분해 볼 수 있지만, 새 발전량 모델 학습/튜닝/추론, 예측 파일 생성, V2/평가 구간 사용과 공식 제출은 모두 0회다. 요인 추정과 예측 모델 학습을 혼동하지 않는다.

## 실행과 검증

정규 CPython 3.13.1의 승격 Start-Process 경로로 환경 점검, 합성 검증, 본 분석과 저장 결과 검증을 실행했고 모두 종료 코드 0으로 완료했다. 합성 검증 8개는 FFT와 직접 순환이동의 동치, 충분통계와 직접 상관의 동치, 알려진 요인의 회복, 순서/부호 정렬, 잘못된 행렬 거부, 달력 편차와 귀무 행렬 대각, 블록 구성과 충돌 중복 날짜 제외를 확인했다.

저장 결과 검증에서는 주 뷰 12개와 민감도 6개, 2024/2023 요인 재구성 24건의 표본 수, KMO, 고유값, PCA, 공통성/독자성, 잔차와 재현 일치도를 별도 수식으로 확인했다. 원본 6개 파일의 SHA-256은 실행 전후와 재검증 때 동일했고 분석 코드 해시는 실행 전후 동일했다. 부트스트랩 합계와 민감도의 같은 행 조건도 점검했다.

그림 8개와 갤러리 링크 16개를 검사하고 모든 그림을 50% 크기의 4개 묶음 두 장에서 직접 확인했다. 원본 크기 전체 픽셀을 검사했다는 뜻은 아니다. 적합 실패를 표시한 제목과 적재량, 안정성의 빈 막대가 구분됨을 확인했다.
