# DA-004 발전소 상대 수준의 시간 구조

작성: 2026-10-21 KST

## 질문과 목적

같은 B 지점에 연결된 발전소와 비교한 상대 발전 수준에 지속적인 시간 변화가 있는가? DA-002의 연간 곡선 유형 재현과 기간 안의 수준 안정성은 다른 질문이다. 이번에는 상대 수준의 단일 변화 후보를 분석하며 기상 관계 계수 전체나 공통 발전 수준의 변화까지 검증했다고 해석하지 않는다.

## 사용 범위

2023~2024년 기록이 완전한 공통 80개소를 출발 표본으로 고정한다. 같은 B 지점에 공통 표본 발전소가 둘 이상 있는 발전소만 상대 비교한다. 시각은 구간 종료이며 한 시간 전의 시작일/시각으로 분류한다. 시작 09~16시 8시간의 energy/capacity_kw 평균을 일별 수준으로 쓴다. 0은 유지하고 음수/비유한 값과 잘못된 용량은 제외한다. 두 해의 모든 날짜와 대상이 완전해야 실행한다. 정적 용량을 과거에 적용한다는 가정이 있다.

이전 DA-003의 실측 패널은 원본 해시와 생성 계약을 검증한 뒤 재사용한다. 발전 원본에서 일별 수준을 직접 다시 만들어 재사용 패널과 일치시킨다. 예보, V2, 평가 자료, 새 예측 모델과 예측 출력은 사용하지 않는다. 원본을 수정하지 않는다.

## 수행 방법과 사전 종료 기준

아래 기준은 변화 통계를 계산하기 전에 기록했다.

1. 각 발전소의 일별 CF에서 같은 B 지점의 나머지 대상 발전소의 동일 날짜 평균 CF를 뺀다. 발전소가 하나인 지점은 제외한다. 공유 지점/날짜의 변동을 제거하는 비교이며 실제 일사나 모든 지역 날씨를 통제한 결과는 아니다. 비교 대상의 변화도 차이에 반영된다.
2. 두 해에 동일하게 반복되는 연간 3차 Fourier 조화항과 절편으로 상대 차이를 설명하고 잔차를 만든다. 윤년을 반영해 각 연도 길이로 날짜 위상을 정한다. 연도별 절편과 추세는 넣지 않는다. 6차 조화항을 미리 정한 계절 민감도로 비교한다.
3. 양쪽에 최소 90일이 남는 모든 단일 분할에서 잔차의 전후 평균 차이를 `sqrt(k*(n-k)/n)/잔차 표준편차`로 표준화한 절댓값을 계산한다. 발전소마다 최대값과 날짜를 저장한다. 이는 탐색 날짜이며 실제 발생일의 신뢰구간이 아니다.
4. 계절 설명을 제거한 전체 발전소 잔차를 같은 날짜 인덱스로 함께 재표집한다. 7일 순환 블록 499회, 14일 블록 499회를 고정한다. 각 표본에 계절 성분을 더한 뒤 같은 계절항을 다시 적합하고 모든 발전소/날짜 최대 통계를 저장한다. 보정 p값은 `(1 + 전체 최대 통계가 관측 발전소 최대 이상인 횟수)/500`이다. 공간 반복과 날짜 탐색을 함께 반영하는 경험적 전역 기준이며, 정상성 가정의 정확한 유한표본 검정이라고 주장하지 않는다.
5. 주 분석 3차와 민감도 6차 각각 두 블록 길이에서 보정 p<=0.05인 경우만 통계적 반복 후보로 둔다. 두 계절식의 탐색일이 60일 이내이고 변화 방향도 같아야 한다. 주 분석 탐색일 직전/직후 90일을 30일씩 나눠 가까운 구간끼리 비교한 세 차이가 모두 전체 방향과 같고, 90일 평균 차이 절댓값이 CF 2%p 이상이어야 지속 변화 후보로 부른다. 사후 선택 효과의 신뢰구간이나 설비 원인으로 해석하지 않는다.
6. 탐지되지 않은 발전소도 안정성이 증명된 것으로 표현하지 않는다. 한 번의 변화만 찾는 방법은 단기 이상, 왕복 변화와 완만한 변화에 한계가 있다. 동료의 이상이 함께 반영될 수 있으므로 발전소별 독립 장애 수로 세지 않는다.

무작위 시드 2026102104, BLAS 스레드 1개를 사용한다. 원본/코드/사전 보고서 해시, 패널과 통계/재표집 결과는 무시된 로컬 출력에 보존한다. 합성 자료로 계절 제거, 알려진 변화와 전역 보정, 기간 경계를 확인한다. 독립 검산으로 원본 일평균, 동료 차이, 최소제곱 잔차, 탐색 통계와 p값을 다시 계산한다. 정해진 범위를 실행하고 불확실성을 기록하면 종료한다.

잔차 누적 변동을 이용한 구조 변화 검정의 개념은 [statsmodels 공식 설명](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.breaks_cusumolsresid.html)을 참고했다. 이번 절사 분할 최대 통계와 공동 블록 보정은 아래 코드에 명시적으로 구현하며 해당 함수의 점근 p값을 사용하지 않는다.

### 개별 발전소의 독립 사건 수로 세면 안 된다

DA-002에서 연간 정규화 곡선 유형이 유지됐다는 결과와 이번 결과는 함께 성립할 수 있다. 연간 모양의 소속이 같아도 동료 대비 수준은 기간 중 달라질 수 있다. 두 유형이 모든 시간 구조의 안정성을 보장하는 것은 아니다.

### 검증과 실행 이력

합성 테스트 9개가 통과했다. 원본 일별 집계 58,480셀과 동료 차이 51,170셀을 별도 계산하고, SVD 최소제곱 잔차와 직접 전후 평균으로 두 계절식의 전체 탐색 통계를 검산했다. 네 설정 280개 전역 p, 저장 참조 분포 1,996개와 최초 재표집 4개의 별도 재구성, 후보 판정과 거울 관계를 확인했다. 전체 1,996회를 독립 재실행했다고 주장하지 않는다. 원본 두 파일과 계산 코드 해시를 전후 확인했다.

첫 계산은 pandas 날짜 검증 함수의 인자 호환성 오류로 통계 계산 전에 중단했다. 날짜 목록을 직접 비교하도록 고친 뒤 동일 계약의 계산을 완료했다. 검산에서는 사전 문서 복사본의 LF/CRLF 차이를 정규화해 원래 내용 해시를 확인했고, 이 분석이 생성한 지점 문자열 배열의 저장 형식을 명시해 읽었다. 통계나 임계값을 바꾸지는 않았다.

그림 8개를 로컬에 생성해 파일과 갤러리 링크 16개를 확인했다. 절반 크기 검토 시트 두 장에서 원래 경로, 계절식과 잔차, 필터, 전역 참조와 민감도를 확인했다. 겹친 두 발전소 표기를 묶어 수정한 뒤 다시 확인했다. 개별 패널과 재표집 결과, 그림은 `data/analysis/2026-10-21_temporal_relative/`에 로컬로만 보존한다.

이번 종료 범위는 같은 B 지점 동료 대비 수준의 반복 계절 제거 후 단일 변화다. 기상 관계 계수 전체와 지점 공통 수준의 안정성을 검증한 결과는 아니다. 같은 B 지점이라도 실제 일사와 방향, 지역 기상 차이는 남는다. 정적 용량의 과거 적용과 두 해로 추정한 계절식에도 한계가 있다.

공동 블록 재표집은 잔차의 대략적인 정상성과 선택한 의존성 범위를 가정한다. 변화가 포함된 잔차를 다시 표집하므로 전역 경험적 p는 참조 기준이며 유한표본 오류율의 보장을 뜻하지 않는다. 7/14일보다 긴 의존성과 변동성 변화, 단기 이상과 왕복 변화, 완만한 이동, 여러 변화는 이번 단일 분할 분석으로 충분히 다루지 못한다. 원인을 밝혀야 종료되는 작업으로 확장하지 않는다.

분석 관점의 결론은 **일중 곡선의 연간 유형만으로 모든 발전소의 상대 수준이 시간 내내 일정하다고 가정하기 어렵다**는 것이다. 시간별 수준 변화가 향후 설명 변수나 학습 기간 판단에 도움이 될 가능성은 있으나 성능 개선은 미검증이다. 이번 결과로 값을 보정하거나 기간을 삭제하지 않는다.

정한 분석과 민감도, 독립 검산 및 한계 기록을 마쳐 DA-004를 종료한다. 다음 우선 후보는 DA-005 A/B의 공통/고유 정보 구조다. 원인 추적이 필요하면 기존 EDA-009와 DA-008의 추가 자료 보류 범위에 연결하며 자동 실행하지 않는다.
