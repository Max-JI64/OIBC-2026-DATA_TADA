# 분석 결과 종합과 후속 질문 검토

작성: 2026-10-21 KST. 상태: 기존 결과의 종합 검토와 후보 우선순위 조정 완료. 새 통계 계산은 미실행.

## 질문과 목적

지금까지의 EDA와 DA-001~005를 종합해 추가 분석이 실제로 필요한지 판단한다. 이미 답한 질문, 아직 해석 범위가 좁은 질문, 새로 연결할 질문을 구분하고 다음 작업을 제안한다.

추가 분석의 가치는 있다. 우선 확인할 부분은 장기 관측 표본의 적용 범위, 기상 조건부 관계의 지지 범위, A/B에 남는 변동과 발전량의 관계다. 분석 방법을 더 많이 적용하는 것 자체를 목표로 두지 않는다.

## 사용 범위와 수행 방법

[EDA 종합](2026-10-19_10_EDA_종합과_남은_판단.md), [데이터 분석 전환](2026-10-21_05_EDA_점검과_데이터분석_전환.md), 아래 다섯 실행 보고서와 두 진행 계획, README 및 일별 기록을 읽어 대조했다. 수치는 해당 보고서의 기존 결과를 인용했으며 이번에 원본을 재집계하거나 계산 결과를 독립 재검산하지 않았다. 일부 분석의 재현 결과도 같은 개발 자료에서 확인한 것이며 새로운 독립 미래 검증으로 취급하지 않는다.

후속 방법의 방향은 제안이다. 실제 실행 때 자료 가용성을 먼저 확인하고 대상, 대비, 불확실성 계산과 종료 기준을 별도 보고서에 고정한다. 이번에는 데이터 원본, 분석 코드와 기존 결과 파일을 변경하지 않았다.

## 권장 순서와 판단을 바꾸는 질문

### 1. 장기 관측 표본의 결론을 어디까지 적용할 수 있는가: DA-010 신규 후보

이 질문을 먼저 권한다. DA-002/003은 두 해 공통 80개소, DA-001/005의 기상 지점 선정은 2024년 완전 기록 148개소를 기준으로 했다. EDA에서 148개소의 현재 그룹 구성은 A 126개/B 22개였지만 전체 253개소는 A 134개/B 119개였다. 여기서 그룹 A/B는 기상 제공처 A/B와 다른 구분이다. 80개소의 그룹 구성은 이 수치로 대신 추정하지 않는다.

현재 결과가 잘못됐다는 증거는 아니다. 다만 장기 기록 표본의 결과를 전체 발전소의 특성으로 확장할 근거가 아직 부족하다. 단순히 전체 집단 평균을 다시 계산하면 관측 시기 차이와 발전소 차이가 섞인다.

- 제안 범위: 기존 train 자료의 2023~2024년에서 장기 80개소, 그 밖의 2024년 완전 기록 68개소, 나머지 105개소를 구분한다. 기록 시작을 설비 가동 시작으로 해석하지 않는다.
- 수행 방향: 실제 겹치는 날짜/시간과 계절, 기상 조건을 먼저 확인하고 같은 구간으로 제한한 곡선 형태와 용량 대비 수준을 비교한다. 공동 지지가 충분한 범위에서만 미리 정한 기상 관계의 집단 차이를 추가로 본다. 관측 기간 차이를 제거한 뒤 남는 차이가 있는지가 질문이다.
- 산출물: 기존 결론별로 적용 가능한 집단/계절, 관측 조건이 겹치지 않는 부분, 구성 차이를 맞춘 뒤에도 남는 차이를 정리한다. 겨울의 짧은 공통 구간만 있으면 그 결과를 연간 유형이나 여름 반응으로 확대하지 않는다. 모든 253개소에 연간 군집을 억지로 부여하지 않는다.
- 종료 기준: 비교 가능한 범위와 비교 불가능한 범위를 구분하면 종료한다. 지지가 부족한 집단은 부족하다는 결론을 허용하며, 가중치로 관측하지 않은 계절의 정보를 복구했다고 주장하지 않는다.

이 결과는 다음 분석의 표본을 어디까지 넓힐지 바꾼다. 전체 일반화가 불가능해도 기존 80개소의 제한된 설명 분석은 계속할 수 있다.

### 2. 기존 기상 관계가 실제 비교 가능한 조건에서도 유지되는가: DA-007

DA-003에서 2024년 B 실측 강수 0→1 mm의 대비는 운량 75% 조건에서 단독 관계 약 -23.5%p에서 공동 관계 약 -2.2%p로 줄었다. 예보 습도 40→80%의 공동 대비는 2024년 -30.43%p, 2023년 -28.26%p로 반복됐다. 전자는 동반 기상 조건의 중요성을 보여 주며, 후자의 크기를 실제 습도 변화의 효과로 바로 해석할 수는 없다.

기존 근방 지지는 모든 기상 변수가 동시에 비슷한지까지 확인한 결과가 아니다. 특히 기온 10→30도처럼 넓은 대비는 같은 발전소/월/시간 안에서 충분히 비교 가능한지 확인이 필요하다.

- 수행 방향: 습도와 운량의 제한된 대비를 우선 정하고 다른 기상 조건도 겹치는 표본에서 관계를 다시 확인한다. 날짜 고정효과를 넣는 민감도에서는 남는 기상 변동과 지점 수를 함께 보고한다.
- 해석 주의: 날짜 고정효과를 추가하면 같은 날 지점 간 차이에 더 의존하는 등 비교 대상이 달라진다. 계수 감소만으로 기존 관계가 허위였다고 판정하지 않는다. 설명 목적의 관계이며 인과효과를 식별하는 작업으로 부르지 않는다.
- 종료 기준: 지지되는 대비 범위, 두 해의 방향/크기와 불확실성, 날짜 조정에 따른 변화를 기록한다. 충분한 지지가 없으면 대비를 제한하거나 추정 불가로 끝낸다.

이 분석은 기존 관계를 어느 조건까지 설명에 사용할 수 있는지 바꾼다. 이후 A/B의 추가 관계를 조사할 때도 같은 지지 기준을 적용할 수 있다.

### 3. A/B에 남는 변동이 발전량과도 관련되는가: DA-011 신규 후보

DA-005에서 2024년 운량의 선형 잔여 분산은 A 약 60~61%, B 약 68~71%였고 B UV는 약 80~82%였다. 이는 반대 제공처로 선형 설명되지 않는 변동이다. 그 크기가 발전량과의 관련성이나 예보 정확도를 뜻하지 않는다. DA-003은 B 중심의 관계를 분석했으므로 두 결과 사이의 연결은 아직 비어 있다.

- 수행 방향: 같은 발전소/시각 패널에서 달력과 상대 제공처의 변수군을 고려한 뒤 남는 발전량 변동과 대상 기상 변동의 관계를 양방향으로 확인한다. 운량과 B UV를 우선 후보로 두고, 지지가 충분할 때에만 강수 조건을 제한적으로 비교한다.
- 방법 후보: 사전 고정한 설명식의 부분회귀와 조건부 설명 분산 증가, 연도별 재현 및 공동 날짜 블록 불확실성이다. 부분회귀에서는 반응과 대상 설명 변수 양쪽에서 같은 나머지 설명 변수를 제거한다. [statsmodels의 부분회귀 설명](https://www.statsmodels.org/stable/examples/notebooks/generated/regression_plots.html)을 방법 참고로 확인했다.
- 분석 단위: DA-005의 52쌍 자료를 발전소 수만큼 복제해 독립 관측으로 세지 않는다. 발전량 패널에 맞춰 변환을 다시 정하고 공유 기상 지점과 날짜의 의존성을 고려한다. 기존 CCA 잔여값을 다른 표본의 발전량에 그대로 붙여 결론 내리지 않는다.
- 해석 주의: 변수를 추가한 표본 내 설명 분산 증가만으로 유용성을 확정하지 않는다. 방향, 불확실성과 기간 재현을 함께 판단한다. 제공처 간 중복과 억제 관계가 있어 설명 분산을 항상 양의 고유/공유 기여율로 분할할 수 있다고 가정하지 않는다.
- 종료 기준: 반대 제공처를 고려한 뒤에도 반복되는 관계, 불확실한 관계, 조건 부족을 구분한다. 예측 오차 최소화나 변수 조합 탐색은 수행 범위에 넣지 않는다.

이 결과는 두 자료의 차이가 발전량과 관련되는지를 설명한다. 향후 모델링 가설의 근거가 될 수 있으나 모델 성능 개선이나 어느 제공처가 더 정확한지를 확정하지 않는다.

### 4. 일시 현상과 지속 변화의 구분: DA-009

PV112는 원래 상대 차이의 두드러진 구간이 2024년 봄에 집중됐지만 반복 계절식 이후에는 2023년 분할이 선택됐다. PV117도 지속 크기 기준에 가깝고 후반에 상대 차이가 다시 줄었다. 따라서 DA-009의 필요성은 남아 있다.

다만 현재 보고서는 이미 실제 변경일을 확정하지 않았고, 이 결과로 데이터를 보정하거나 삭제하지도 않았다. 전체 자료의 적용 범위와 관계 해석보다 먼저 해결해야 하는 필수 작업은 아니다. 다음 작업에서 변화일을 사용하거나 기간을 나눌 목적이 생기면 우선순위를 올린다.

제안 범위는 두 후보와 해당 동료 경로에 한정해 반복 계절, 일시 구간과 지속 단차의 소수 비교식을 먼저 고정하는 것이다. 같은 자료에서 후보를 선택했다는 한계를 유지하며, 다른 표현에서도 현상의 위치/지속이 구분되는지 확인하고 끝낸다. 계절 추정만으로 발전소 운영 원인을 확정하지 않는다.

## 다른 분석으로 남길 질문

### 발전소별 기상 반응의 차이: DA-012 신규 선택 후보

DA-002의 두 유형은 일중 모양의 차이다. DA-003의 발전소별 관계 산포만으로도 유형 간 반응 차이를 검증했다고 볼 수 없다. 같은 운량/습도 조건에서 발전량 감소의 크기가 유형 또는 발전소마다 다른지를 제한된 교호작용이나 계층적 기울기 분석으로 살펴볼 수 있다.

DA-010/007에서 비교 가능한 표본과 조건을 정한 뒤 검토한다. 기존 유형을 고정하고 운량/습도 대비를 소수로 제한하며, 같은 기상 지점 안에서도 유형 차이를 비교할 수 있는지 확인한다. 곡선으로 만든 유형을 같은 곡선 차이로 재확인하는 순환을 피하고 별도 기간의 관계를 보되, 이미 분석에 쓴 두 해를 새로운 독립 검증이라고 부르지 않는다. 반복되는 반응 차이와 지지 부족을 구분하면 종료한다. 이를 위해 새 군집 수나 알고리즘을 계속 탐색하지 않는다.

### 기상 조건을 고려한 발전소 공동 변동: 기존 EDA-004 유지

발전소 간 달력 제거 후 동시 변동은 확인했지만, 공동 기상 조건으로 설명되는 부분과 그 뒤에도 함께 남는 변동의 구분은 남아 있다. 전체 변화, 공유 기상 지점과 개별 발전소 수준의 변동을 나눠 보는 방향은 데이터 이해에 의미가 있다.

기존 EDA-004와 겹치므로 새 ID를 만들지 않는다. 현재는 선택 후보를 유지한다. 추후 단순 조건별 비교를 넘어 계층적 분산 분해를 실행하려면 해당 항목에 범위 확장 이유와 대상, 날짜/지점 의존성 처리 및 종료 기준을 먼저 기록한다. 집합 최적화나 원인 규명으로 자동 확장하지 않는다.

## 현재 추가 실행을 권하지 않는 범위

| 항목 | 현재 판단과 재검토 조건 |
|---|---|
| DA-006 A 요인분석 재시도 | 선택으로 유지한다. 안정적 압축이 필요한 목적이 생기면 제한된 요인 수/변수군을 비교한다. 좋은 해가 나올 때까지 방법을 바꾸는 작업은 우선하지 않는다. |
| DA-008 설비 방향/운영/기록 원인 | 추가 메타와 원기록 정의가 필요하다. 약 15분의 형태 중심 차이로 시간 오류를 확정하지 않는다. |

| 인과효과 추정이나 구조방정식의 즉시 적용 | 인과 방향과 식별을 뒷받침할 자료/설계가 아직 정해지지 않았다. 설명 관계의 강함만으로 전환하지 않는다. |

## 한계 및 다음 단계

권장 순서는 DA-010 표본 적용 범위 → DA-007 공동 지지와 날짜 요인 → DA-011 A/B 잔여 변동과 발전량 관계다. DA-009는 목적이 생기면 실행할 선택 심화로 유지하고, DA-012와 기존 EDA-004는 앞선 결과를 본 뒤 검토한다. 모든 후보의 실행이 데이터 분석 종료의 필수 조건은 아니다.

이번 작업으로 DA-010/011/012를 후보 등록하고 DA-009 단독 우선에서 위 순서로 재조정했다. 새로운 결과를 만들어 낸 것이 아니라 기존 근거에 따라 후속 질문을 선택한 것이다. 현재 진행 중인 수치 분석은 없으며 예측 모델링 중단을 유지한다.

공개 문서 5개의 로컬 링크 109개와 금지 기호를 검사했고 변경 사항의 공백 오류를 점검했다. 코드 변경과 Python 실행은 없었으므로 새 계산이나 테스트를 검증했다고 표현하지 않는다.
