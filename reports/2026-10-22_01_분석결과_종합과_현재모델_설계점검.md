# 분석 결과 종합과 현재 모델 설계 점검

작성: 2026-10-22 KST. 10월 21일에 검토를 시작하고 자정 이후 문서를 마무리했다. 상태: 기존 문서와 코드의 읽기 검토 완료. 새 수치 분석과 모델 실행 없음.

## 질문과 목적

기본 EDA, DA-001~005와 후속 DA-010/007/011/012의 결론을 종합하고, 현재 우선 참조 B3가 이미 처리하는 내용과 아직 검증하지 못한 설계 문제를 구분한다. 다음 실험은 하나의 검토 후보로만 제안한다. 이 문서는 예측 모델링 재개 승인이나 실행 결과가 아니다.

판단은 **B3 유지, 기존 기상 입력 유지, 유형별 별도 모델과 전체 요인 대체 보류**다. 발전소별 곡선 차이를 표현할 여지는 남지만, 현재 모델이 그 차이를 학습하지 못했다고 입증한 것은 아니다. 후속 후보로는 공유 B3에 발전소 ID 범주 입력 하나를 더하는 비교를 제안한다.

## 사용 범위와 수행 방법

AGENTS.md, AGENT_MEMORY.md, README, 데이터 분석/성능 개선 계획과 10월 21일 일별 로그를 먼저 확인했다. 필요한 개별 EDA/DA 보고서와 모델 비교 보고서, 실제 특징 생성/학습/집계 코드를 읽었다. 로컬 B3의 fit_summary.json과 저장 모델의 목적함수/입력 이름도 텍스트로 확인했다. 모델을 라이브러리로 로드하거나 실행하지 않았다.

10월 19일 EDA 종합과 10월 21일 11번 종합은 당시의 기록과 보고서 안내로만 사용했다. DA-010/007/011/012가 완료된 이후의 적용 범위와 종료 판단은 각 후속 보고서를 우선한다. 기존 자료에 담긴 평가 예보의 분포 변화와 V2 사용 이력은 읽었지만, 평가 원본이나 V2 예측을 새로 분석하거나 점수를 다시 계산하지 않았다.

이번 검토에서는 새 EDA, 추가 통계 분석, Python 실행, 모델 코드 수정, 학습, 튜닝, 추론, 새 예측 파일 생성과 공식 제출을 하지 않았다. 아래 수치는 모두 기존 보고서/저장 메타데이터의 값이며 새 계산값이 아니다. 기존 그림을 새로 시각 검수했다는 의미도 아니다.

### 후속 분석으로 달라진 최종 판단

1. 기본 EDA의 단순 음의 운량/습도 관계는 관측 사실로 남는다. 독립적인 큰 효과라는 해석은 DA-003/007의 공동식과 지지 부족 때문에 제한한다.
2. DA-002의 곡선 재현은 80개소에서 지지된다. DA-010 이후 전체 253개소 연간 유형으로 일반화하지 않고, DA-004 이후 모든 상대 수준이 일정하다고 가정하지 않는다. DA-012 이후 유형별 기상 반응 모델 분리를 우선하지 않는다.
3. DA-005의 선형 잔여 변동 중 일부는 DA-011에서 발전량과도 관계가 남았다. 따라서 모두 무용한 잡음이라고 할 수는 없다. 다만 B UV의 작은 ΔR²가 보여 주듯 잔여 분산의 크기를 예측 효용으로 바꾸어 말할 수 없다.
4. 분석을 완료했다는 것은 사전 범위의 질문을 정리했다는 뜻이다. 인과효과, 실제 운영 원인, 발전량 예측 성능 개선을 확인했다는 뜻이 아니다. DA-006/009와 기존 EDA 선택/보류는 자동 실행할 필수 과제가 아니다.

주 지표는 다음 로컬 W다. 구성원이 모두 관측된 고정 시각만 채점하고 정답은 자르거나 0으로 채우지 않는다.

```text
W = sum_t SMP(t) * k(t) * sum_g abs(sum_{i in g}(예측_it - 실제_it))
k(t) = 종료 시각 11~15시에는 3, 나머지는 1
```

[완전성 마스크와 합산](../scripts/validation_core.py#L126), [local_score 150행](../scripts/validation_core.py#L150), [기간별 분할 점수](../scripts/b2_joint_compare.py#L49)를 확인했다. 개별 CF L1은 이 집합 W를 직접 최소화하지 않는다. 집합 안 오차 상쇄와 용량/가격/k가 평가에서 작용한다. 공식 채점기와 구현 동치는 기존 기록상 미확인이며 이번에 새로 확인하지 않았다.

## 4. 다음 우선 가설 하나: 공유 B3에 발전소 ID 범주 입력

### 가설과 근거의 강도

**P-006 검토 후보:** B3의 기존 39개 입력에 site_id를 명목 범주로 추가해 40열로 만들면, 같은 공유 모델 안에서 발전소별 시간 배분 차이를 더 쉽게 표현해 집합 W를 줄일 수 있는가?

근거는 DA-002의 반복된 곡선 형태와 같은 기상 지점으로 다 설명되지 않은 차이다. DA-012의 결과는 두 유형별 기상 반응 모델 분리를 뒷받침하지 않으므로 유형 레이블을 사용하지 않는다. ID는 기존 메타의 키이며 새 기상 관측을 추가하는 안도 아니다. 현재 39입력에서 빠져 있는 구분 표현 하나만 시험한다.

기대는 기존 hour/태양/계절 변수와 ID의 트리 분기가 발전소별 평균 곡선 차이를 표현하는 데 도움이 되는 것이다. **현재 cap/lat/lon이 이미 그 차이를 충분히 나타낼 수 있고, 분석은 B3의 미설명 곡선 오차를 입증하지 않았다.** 짧은 기록에서는 과적합하거나 관측 긴 발전소를 더 외울 수 있다. DA-004의 시간 변화도 정적 ID만으로 해결하지 못한다. 따라서 이 가설은 제한된 비교를 할 이유가 있는 표현 후보이며 우선 변경이 확정된 결함 수정은 아니다.

DA-010 때문에 80개소의 결론을 전수 효과로 전제하지 않는다. 긴 표본과 최근 확장 표본을 함께 확인하는 기존 네 개발 구간을 유지한다. 유형을 2023/2024 전체 발전량에서 미리 만들어 과거 T0 입력으로 넘기는 정보 누출도 피한다.

### 채택과 중단 기준 제안

이전 H1의 네 구간 기준을 그대로 주 판단으로 제안한다. 실행 전에 확정하며 결과를 보고 바꾸지 않는다.

1. T0와 V1의 연간 W가 B3보다 각각 엄격히 작다.
2. T0/V1의 어느 분기도 W가 5% 초과 악화하지 않는다.
3. R3와 R4의 분기 전체 W가 각각 엄격히 작다.
4. R3/R4의 어느 월도 W가 5% 초과 악화하지 않는다.

상대 동률 허용오차는 기존 rtol=1e-12, atol=0이다. 참조 W=0이면 후보도 0일 때만 한도 통과이며 주 구간의 엄격 개선은 성립하지 않는다. 한 조건이라도 미통과하거나 동률이면 후보를 채택하지 않고 B3를 유지한다. 5%는 기존 개발 운영 기준으로, 통계적 유의성이나 허용 손실을 추정한 값이 아니다.

학습 전 계약 불일치, ID 사전/시간 누출/특징 타입 문제, 전체 격자 손실, 비유한 예측, 저장 재로드 불일치나 점수 재현 실패는 평가를 해석할 수 없는 중단 사유다. 이를 성능 실패와 구분하고 자동 예산 증액이나 다른 가설 시험으로 이어가지 않는다. 성공 시에도 점수표, 분할 합계와 저장 결과의 판정 재현까지 확인한 후 종료한다.

모든 기준을 통과해도 이미 본 개발 자료에서 우선 후보가 됐다는 뜻이다. V1과 R3/R4는 겹치고 단일 적합의 난수/통계 불확실성은 남는다. 입력 수가 달라지면 기존 특징 샘플링 경로도 바뀔 수 있으므로 ID 정보만의 인과 기여를 분리하는 실험은 아니다. 전체 253개소의 연간 정답 부족도 해결하지 못한다. 독립 시험 통과나 공식 제출 개선으로 표현하지 않으며 V2/제공 평가 구간 재평가, B3 평가 예측 교체와 공식 제출은 별도 요청 없이 진행하지 않는다.

## 한계와 종료 판단

현재 B3의 입력/처리가 분석과 충돌하는 명백한 차단 오류는 이번 정적 검토에서 확인되지 않았다. 이는 계산 정확성/일반화 성능을 새로 검증했다는 뜻이 아니다. 남은 설계상 쟁점은 발전소별 곡선 표현의 충분성, 관측 길이별 적용 범위와 개별 CF L1/집합 W의 차이다. 각각 범주 ID 비교 후보, 검증 한계, 이미 시험한 가중 대안과 구분해 둔다.

유형별 분리, 전체 요인 대체, 큰 습도 효과 기반 고정보정, 기압/집중값 자동 보정과 변화일 기반 기간 삭제는 현재 근거로 채택하지 않는다. 분석 결과의 미확정을 이유로 새 EDA를 늘리지 않는다. P-006 하나를 미실행 후보로 등록하고 이번 문서 검토를 종료한다. 기본 EDA와 DA 완료, 기존 선택/보류 및 예측 모델링 중단을 유지한다.
