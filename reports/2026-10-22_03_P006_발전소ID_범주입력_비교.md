## 질문과 목적

사용자가 사전 입력 점검, 네 구간 비교, 저장 검증과 결과에 따른 다음 방향 판단을 모두 실행하도록 요청했다. 공유 B3의 기존 39열에 명목 발전소 ID 1열만 추가하면 같은 표본의 집합 W가 개선되는지 확인한다. [분석 종합](2026-10-22_01_분석결과_종합과_현재모델_설계점검.md)과 [모델링 전 검토 P-007](2026-10-22_02_모델링전_문제정의와_방법검토.md)의 가설과 한계를 유지한다.

## 결과 확인 전 고정한 실행 계약

- 비교 대상은 저장된 B3다. 원본, 기존 특징/학습 코드, 실행 환경, 구간과 학습 행/경계/목표 해시가 기존 참조와 맞아야 재사용한다. 불일치 시 학습 전에 중단하고 자동 재학습하지 않는다.
- 새 특징은 마지막 `site_id_category` 1열이다. 기존 39열은 값/순서/float32/NaN을 유지한다. 낮 학습 행에서 관측한 ID만 정렬해 비순서 범주 사전을 만들고 fit에 범주를 명시한다. 미관측 ID는 후보 모델의 결측 분기로 처리하며 B3 fallback으로 표현하지 않는다.
- 기존 낮 선택, 목표 clip, L1, 행 동일 비중, 600트리와 기존 샘플링/난수/정규화, 학습 기간/집합, 야간/음수 처리와 상한 미적용을 유지한다. LightGBM 4.6.0의 범주 기본값 cat_smooth=10, cat_l2=10, min_data_per_group=100, max_cat_threshold=32, max_cat_to_onehot=4를 고정하고 탐색하지 않는다.
- T0/V1/R3/R4 각 후보 1회, 총 4회만 적합한다. 각 구간 253개소의 개발 예측 격자를 유지한다. 주 표본은 저장된 80/148/224/252개소다. 첫 점수와 관계없이 네 구간을 실행하되 구현/계약 오류에서는 중단한다. 부분 실패 모델은 자동 재적합하지 않는다.
- 주 판단은 T0/V1 연간 W 각각 감소, 어느 분기도 5% 초과 악화 없음, R3/R4 전체 W 각각 감소, 어느 월도 5% 초과 악화 없음의 네 조건이다. 동률 rtol=1e-12, atol=0, 참조 W=0에서 엄격 개선은 성립하지 않는다. 하나라도 미통과하면 B3 유지다.
- G1/G2, k=1/3, 기존/추가 완전 표본, 학습 ID 관측/미관측과 common_253, 과대/과소 비용을 함께 기록한다. 양 집합이 없는 소집합은 개별 오차와 가용성만 기록한다. 소집합 W를 더해 전체 W로 해석하거나 좋은 조건만 선택하지 않는다.

전체 개발 예측 격자의 키, 유한/비음수와 해시를 검증했다. 저장 점수/채택 판단과 그룹/시간 가중/과대/과소 진단을 재현했으며 월/분기/k 분할 합계도 점검했다. 저장 검증에서 새 적합은 0회다. V2와 제공 평가 구간의 새 실행은 없었다.

## 판단, 한계와 다음 단계

### 요청한 1~4단계의 종료 판단

1. 실제 입력과 저장 참조의 계약을 확인했다. 낮 학습 ID만으로 구간별 범주 사전을 고정하고 기존 39열과 목표값/순서를 보존했다.
2. ID 범주 입력 1열만 추가한 후보를 T0/V1/R3/R4에 각 1회, 총 4회 적합했다. 개발 예측 격자와 원래 출력 처리를 유지했다.
3. 네 구간의 전체 W가 모두 엄격히 감소했고 사전 월/분기 5% 안정성 한도를 넘은 기간도 없었다. 저장 점수와 판정이 재현돼 **P-006을 개발 우선 후보로 둔다.** 결과를 본 뒤 채택 기준을 바꾸지 않았다.
4. 통과 분기에 따라 후보를 고정하고 추가 가설 학습을 하지 않는 방향을 택했다. P-003 정규화 탐색, 부분 풀링과 집합 손실은 검토 후보로 남기며 자동 실행하지 않는다. 기존 최종 B3의 모델/평가 예측 교체와 공식 제출은 이번 단계에 포함하지 않는다.

### 개선과 함께 남은 제한

R4 감소율은 0.0307%로 매우 작다. 사전의 엄격 감소 기준은 통과했지만 난수 반복이나 시계열 블록 불확실성을 추정하지 않았으므로 안정적인 우위나 유의한 개선으로 부를 수 없다. 작은 차이를 보고 새 반복 학습을 늘리지 않았다.

V1 1분기는 2.3924%, R4 11월/12월은 각각 1.8284%/0.7423% 악화했다. 5% 한도 안이라는 사실과 모든 기간에 개선됐다는 주장은 다르다. 네 구간의 W 절댓값이나 감소율을 단순 평균해 전체 효과로 제시하지 않는다.

전체 253개소 공통 정답은 V1/R4의 연말 178시간뿐이다. 해당 W는 V1 +3.7416%, R4 -4.8851%로 방향이 달랐다. 두 결과는 같은 연말 시각을 다른 학습 마감에서 예측한 개발 비교이고 독립 반복이 아니다. 두 주 표본도 148/252개소로 다르다. 짧은 공통 구간을 주 연간 표본이나 전체 253개소 연간 결과로 바꾸지 않는다.

주 평가 표본에는 미관측 학습 ID가 없었다. 격자에는 구간별 173/105/29/1개소가 학습 미관측으로 남아 후보의 결측 분기로 예측됐다. V1의 미관측 105개소 개별 MAE는 6.8934→6.9527kWh로 증가했고, R4의 미관측 1개소 178행은 22.7947→43.2680kWh로 증가했다. R4 전체 공통 W의 개선과 이 개별 악화가 함께 나타났다는 것은 집합 상쇄와 개별 오차를 구분해야 함을 보여 준다. ID 결측 처리가 신규 발전소에 안전하다는 보장이나 기존 B3로의 자동 복귀를 뜻하지 않는다.

일부 학습 ID는 관측이 한두 달뿐이었다. 범주 정규화 기본값이 있다고 해서 관측 길이별 일반화를 확인한 것은 아니다. 그렇다고 이번 결과만으로 짧은 기록의 ID가 과적합 원인이라고 확정할 수도 없다. 기존 cap/좌표/기상과의 중복, 열 추가에 따른 특징 샘플링 변화, 정적 ID로 설명하지 못하는 시간 변화도 남는다.

### 다음 작업의 우선순위

다음 우선 작업은 **P-006의 최종 적용 설계 점검**이다. 최종 적용에 사용할 학습 기간과 마감 이전 낮 관측에서 실제 253개소의 ID/기록 길이/기상 가용성을 확인하고 범주 사전과 입력 계약을 다시 고정해야 한다. 이는 이번 개발 표본으로 이미 입증된 사항이 아니다. 저장 B3와 결과 복원 경로도 보존한다. 이번에 최종 모델을 학습하거나 제공 평가 예측을 생성하지 않았다.

운용 대상에 학습 미관측 ID가 실제로 남는다면 그 처리 정책이 우선 해결할 설계 질문이다. B3 fallback이나 부분 풀링은 별도 후보로 사전에 등록하고 비교해야 하며, 개별 오차를 줄이는 정책이 집합 W도 줄인다고 가정하면 안 된다. 현재의 개발 성능 통과를 이유로 어느 정책도 조용히 추가하지 않는다. 최종 적용 조건을 확인하기 전에는 이 추가 가설을 억지로 정하거나 새 필수 학습을 늘리지 않는다.

현재 근거는 ID를 명시한 공유 모델의 개발 비교를 지지한다. 유형별 모델 분리, 전체 기상 요인 대체, 새로운 가격 가중이나 잔차 보정의 근거로 확대하지 않는다. 전체 253개소의 독립된 미래 정답과 공식 채점 결과는 확보하지 못했으며 V2 재평가로 그 부족을 메우지 않았다.
