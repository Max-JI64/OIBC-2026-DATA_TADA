# P-009 최종 입력 계약 점검

작성: 2026-10-22 KST. 상태: 실행 전 범위 고정.

## 질문과 목적

사용자가 다음 작업 전체 진행과 전체 이력 재검토를 요청했다. P-006의 고정된 최종 입력을 실제로 구성해 학습 목표, 행 순서와 ID 범주가 일치하는지 확인한다. [후속 판단](2026-10-22_04_P006_결과해석과_후속판단.md)의 P-009 범위다.

## 사용 범위와 방법

기존 B3 최종 기간인 대상 날짜 s >= 2023-06-01, 학습 ts <= 2025-05-31 00:00 KST를 유지한다. 기존 원본과 B3 최종 요약/출력 해시를 검증한다. 월별 기존 39개 float32 입력/목표/ID/원래 행 키를 함께 정렬한 뒤 명목 범주 1열을 추가한다. 범주 사전은 실제 낮 학습 ID에서만 만든다. 기존 3,421,168 관측 행, 1,707,268 낮 행, 253개소와 특징 결측 1,382행을 대조한다. 정답 clip과 낮 선택, 원래 행 순서를 유지하고 개소별 가용성은 로컬에만 기록한다.

정렬/키 중복/불일치/미관측 범주/자료형 계약을 합성 테스트로 먼저 검증한다. 출력은 사전 사본, 코드/원본/행/목표/ID/특징 해시와 집계 요약뿐이다. 모델 적합, 추론과 점수는 0회다. P-010 안정성 검토는 별도 실행한다. 실행 뒤 이 문서를 갱신하되 실행 전 사본은 로컬에 보존한다.

## 종료 기준과 후속

기존 39열 값/순서/NaN, 목표와 ID 행 대응, 시간 경계, 대상/낮 관측 범주 253개소와 고정 환경이 모두 맞아야 통과한다. 불일치 시 P-011 최종 적합을 시작하지 않는다. 원래 B3 산출물은 별도 경로에서 보존한다. 기간/가중치/난수/범주 정규화 탐색과 V2 재채점은 없다.

## 실제 결과와 종료 판단

2026-10-22 11:31 KST에 정규 CPython 3.13.1의 실제 입력 점검이 종료 코드 0으로 완료됐다. 합성 계약 테스트는 기존 범주 8개, 새 최종 정렬 5개와 블록 3개를 합쳐 16개가 통과했다. 이 중 P-009에 직접 해당하는 새 정렬 테스트는 5개이며 모델 적합은 없었다.

관측 3,421,168행과 낮 1,707,268행, 253개 학습 범주, 수치 특징 결측 1,382행이 기존 B3 최종 계약과 일치했다. 전 대상에 범주가 존재하며 미관측 대상 ID는 0개다. 개소별 낮 행 최소/최대는 1,833/8,795로 기존 기록과 일치했다. 원래 행 키로 x/y/ID를 정렬하고 기존 B3 결합 함수의 수치 입력 및 목표와 동일함을 확인했다. 실제 학습 입력의 수치/목표/키/ID/범주 코드 해시와 범주 사전을 로컬 사전 기록에 고정했다.

P-009는 통과로 종료한다. 적합/추론/성능 계산은 각각 0회다. 기존 B3와 개발 결과의 보호 해시가 유지됐다. P-010 검산 후 최종 P-011 실행으로 이어갈 수 있으며 신규 ID fallback 실험은 필요하지 않았다. 이 가용성 확인이 전체 대상의 미래 성능 우위를 입증하는 것은 아니다.
