# P-011 P-006 최종 학습과 로컬 출력 검증

작성: 2026-10-22 KST. 상태: 단일 최종 적합/로컬 출력 생성/별도 저장 검증 완료. 아래 고정 범위는 실행 전에 사본으로 보존했다.

## 질문과 목적

개발 우선 후보 P-006을 기존 최종 학습 기간에 한 번 적합해 253개소 평가 1년의 로컬 출력을 생성하고 저장 검증한다. 독립 미래 성능 확인이나 공식 제출 작업이 아니다.

## 고정 범위와 방법

기존 B3 최종 학습 시작/마감, 원래 관측 순서, 기존 39열 float32와 마지막 명목 ID 1열을 유지한다. ID는 낮 학습 사전만 사용한다. L1, 600트리, 기존 설정/난수 정책과 P-006 범주 기본값을 고정한다. 낮 선택/목표 clip/원래 NaN과 야간/음수 출력 0, 용량 환산 및 양의 상한 미적용을 유지한다. 참조 G1/G2 구성은 고정한다. 최종 적합 예산은 1회이며 참조 재학습/튜닝/추가 후보 0회다.

학습 전 P-009 요약, 코드/원본/환경/입력 해시를 다시 대조한다. 적합 장부를 호출 전에 기록한다. 실패/부분 적합에서 자동 재학습하지 않는다. 저장된 완료 모델/입력 해시가 맞으면 추론 재개만 허용하고 이미 검증한 월은 동일 모델 해시로 재사용할 수 있다. 모든 출력은 `data/final/2026-10-22_P006/`에 두고 기존 B3 경로를 보호한다.

평가 예보는 학습 예보와 분리하고 대상 날짜 2025-06-01 이상, 2026-06-01 미만의 8,760시간만 사용한다. 모델을 연중 갱신하지 않는다. 저장 전후/역순/배치 예측, 600트리/40열/범주 사전/유효 설정, 개별 2,216,280키와 집합 17,520키, 그룹 용량/합계, 중복/유한/비음수/야간과 CSV 재읽기를 검증한다. 별도 프로세스에서 저장 모델/전체 출력/월 해시와 전 개소의 월별 표본 입력을 재구성해 다시 확인한다.

## 한계와 종료 기준

P-010의 블록 취약성은 기존 개발 통과를 취소하는 사후 기준으로 쓰지 않는다. 입력 또는 저장 점수 검산 실패는 최종 적합을 막는다. 출력 검증 통과 시 로컬 적용 산출물 완료로 종료하며 정답 없는 평가 구간의 성능 점수는 계산하지 않는다. V2 재평가, 제출과 push는 하지 않는다. 기존 B3 모델/예측은 보존한다.
