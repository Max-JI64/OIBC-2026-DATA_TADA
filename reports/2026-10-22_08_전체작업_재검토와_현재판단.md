# 전체 작업 재검토와 현재 판단

작성: 2026-10-22 KST. 상태: 전체 이력 재검토와 P-009/P-010/P-011 완료. P-006 개발 우선 및 로컬 적용 후보, 기존 B3 보존.

## 질문과 목적

사용자가 다음 작업 전체 실행과 지금까지의 모든 작업을 다시 살펴보도록 요청했다. 원본 확인, 기본 EDA, 심화 DA, 예측모형 비교, 현재 P-006 후속 점검과 최종 적용까지의 결론을 같은 증거 수준으로 맞춰 검토한다. 과거 보고서의 당시 판단을 현재 판단으로 오인하지 않는다.

검토 단위는 날짜별 로그, 독립 보고서와 연결 코드/저장 집계 및 검증 기록이다. 과거 분석 전체를 재실행하거나 모든 그림을 다시 시각 검수한 작업은 아니다. 새 실행은 P-009 실제 입력 점검, P-010 저장 예측 진단, 조건을 통과한 P-011 고정 최종 적용과 문서/집계 메타 점검으로 제한한다.

## 4. 현재 모델에 반영된 내용과 남은 빈틈

P-006은 하나의 공유 LightGBM이다. A/B의 전일 10/17시 기상 30열, 태양/계절/시간/용량/좌표 9열과 명목 ID 1열을 사용한다. 낮 관측의 용량 대비 목표를 clip하고 L1으로 학습하며, 예측을 용량으로 환산한다. 발전소별 별도 모델이나 유형 모델은 아니다. 학습 중 원래 NaN, 예측 전체 격자와 G1/G2 구성, 야간/음수 처리를 유지한다.

| 구분 | 현재 판단 |
|---|---|
| 이미 반영 | 양 공급처/양 라운드, 기상/태양/계절/규모/좌표, L1과 명목 발전소 구분, 시간 순서 검증과 저장 계약 |
| 일부 반영 | 개별 CF L1과 집합 SMP×k 절대 잔차 목적의 차이. 성능 판단에는 W를 쓰지만 학습 손실 자체는 집합 손실이 아니다. |
| 미확인 | 전체 253개소의 독립된 미래 연간 우위, 정적 ID로 다루기 어려운 시간 변화, 학습/평가 기상 분포 변화의 실제 성능 영향 |
| 변경 근거 부족 | 유형별 분리, 전체 기상 요인 대체, 원인 미확정 값의 교정, 새 그룹/계절 혼합과 광범위 튜닝 |

R3는 정한 7일/14일 블록을 하나씩 제외해도 개선 방향이 유지됐다. R4는 7일 14개 중 7개, 14일 7개 중 4개 제외에서 부호가 반전했다. 따라서 P-006을 개발 우선 후보로 쓰는 결정과 R4 우위를 신뢰하는 정도는 분리한다. 후자는 약하다. 주 표본이 학습 관측 ID라는 제한과 전체 공통 정답 178시간의 한계도 유지한다.

## 5. 검토 후의 실행 판단

P-009에서 실제 최종 학습에 253개소 모두의 범주가 확인됐으므로 신규 ID fallback은 현재 필요하지 않았다. P-010에서는 저장 점수나 입력 오류가 없었고 R4의 취약성만 확인됐다. 사전 기준에 따라 기존 개발 선택을 유지하고 설정을 고정한 P-011로 이어간 판단은 가능하다. 이 과정은 안정적인 미래 우위를 확정한 결정이 아니다.

모든 선택 후보를 실행할 이유는 없다. 현재 필요한 적용 계약과 저장 검증을 완료하면 그 범위에서 종료한다. 더 많은 실험을 한다면 P-003 등 기존 후보에서 독립 질문과 예산을 먼저 정해야 하며 R4 차이를 키우기 위한 반복은 하지 않는다. V2는 재사용하지 않고 정답 없는 평가 예측의 차이를 성능으로 판정하지 않는다. 공식 제출과 push는 별도 사용자 요청 범위다.

## 6. 검증 범위와 기록
