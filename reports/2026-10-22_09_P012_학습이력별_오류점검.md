# P-012 학습 이력별 오류 점검

작성: 2026-10-22 KST. 상태: 실제 진단과 별도 재검산 완료. 아래 계약은 실행 전 사본으로 보존했다. 짧은 이력의 반복 악화 근거가 없어 추가 정규화 학습 없이 종료한다.

## 질문과 목적

사용자가 이전 답변의 학습 이력별 점검과 근거가 있을 때의 제한 정규화 비교를 진행하도록 요청했다. 저장된 P-006/B3 예측에서 짧은 학습 기록의 발전소에 악화가 반복 집중되는지 확인한다. R4가 불안정하다는 사실만으로 과적합을 가정하지 않는다. 이 진단은 성능 계획의 P-012이며 기본 EDA/DA를 재개하지 않는다.

## 사용 범위와 수행 방법

R3 224개소/2024년 7~9월과 R4 252개소/10~12월의 고정 주 표본을 유지한다. 각 발전소는 해당 마감 전 낮 학습에서 저장한 관측 월 수와 낮 행 수로만 분류한다. 평가 성능이나 최종 학습 이력으로 분류하지 않는다. 미관측 ID는 주 표본에 없어 분석에 포함하지 않으며, 전체 격자의 신규 ID 진단과 혼동하지 않는다. 같은 구간 내 모든 집단은 동일한 전체 평가 시각을 사용한다. 발전량은 개발 ts <= 2025-01-01로 제한한다. 기상 행, V2 점수와 제공 평가 구간은 읽지 않는다.

결과 전에 다음 구분을 고정한다. 주 기준은 낮 관측 월 수 6개 이하/7개 이상이다. 민감도 기준은 낮 학습 행 수 2,000개 이하/초과다. 두 기준의 교차 일치율과 낮 행/관측 월의 범위를 기록한다. 관측 월은 연속된 실제 운전 개월 수가 아니라 저장 학습 메타의 관측 월 수다. 경계는 대략 반년의 관측량을 구분하는 실무 기준이며 통계적으로 최적인 경계가 아니다. 결과 뒤 경계 탐색이나 재분류를 하지 않는다.

개별 지표는 원시 평가 발전량/고정 용량으로 계산한 CF MAE와 kWh MAE다. 평가 정답을 clip하거나 결측을 0으로 채우지 않는다. 발전소별 CF MAE 변화의 평균/중앙값, 악화 개소 비율을 비교하며 CF 평균은 발전소 동일 가중이다. 이 정규화로 용량 단위의 차이를 줄이지만 위치/날씨/편입 시점과 이력 길이의 교란은 남는다. 인과효과나 정규화 성능 개선의 입증은 아니다.

전체 W는 원래 G1/G2 잔차를 합친 뒤 절댓값/가격/k를 적용해 저장된 점수와 재현한다. 이력 집단별 내부 W를 더해 전체 W로 해석하지 않는다. 대신 짧은 집단 S와 나머지 L의 변화에 대해 두 순서의 비용 차이를 평균해 전체 변화액을 배분한다. 구간/집합/시각에서 `C(X,Y)=q*abs(e_X,S+e_Y,L)`라 할 때 짧은 집단 배분은 `0.5*((C(P,B)-C(B,B))+(C(P,P)-C(B,P)))`이며 긴 집단은 나머지다. 두 합이 전체 P-006-B3 W 변화와 같아야 한다. 이는 집합 상쇄를 포함한 대수적 배분이며 독립적인 집단의 성능 효과, 실제 혼합 모델 또는 운영 정책 비교가 아니다. G1/G2와 k=1/3 분할의 합도 확인한다.

## 실행 전 후속 판단 기준

정규화 비교로 이어갈 관측 근거는 다음 조건을 R3/R4와 두 이력 정의 모두에서 충족할 때만 인정한다.

1. 짧은 집단과 비교 집단이 각각 최소 10개소다. 이 최소값은 해석을 위한 지지 기준이며 유의성 기준이 아니다.
2. 짧은 집단의 평균 CF MAE 변화, 중앙값 변화가 모두 악화 방향이고 악화 개소가 절반을 초과한다.
3. 짧은 집단의 평균 CF MAE 변화가 비교 집단보다 나쁘다.
4. 짧은 집단에 배분된 전체 W 변화액도 악화 방향이다.

한 조건이라도 충족하지 못하면 이번의 '짧은 이력 악화 반복' 가설로는 P-003 학습을 시작하지 않는다. 지지 부족과 악화 반복의 부재를 구분한다. 한 구간이나 지표만 골라 기준을 완화하지 않는다. 조건을 충족하더라도 과적합의 확정은 아니며 별도 사전 계약에 범주 정규화 한 설정만 바꾸는 후보와 T0/V1/R3/R4 각 1회 예산/채택 기준을 기록한 뒤 실행한다. 지지 조건만으로 모델을 채택하지 않는다.

## 검증과 종료 기준

결과 전 코드/사전 문서를 로컬 동결한다. 합성 테스트로 배분의 합/대칭/상쇄, 반복 악화 기준과 지지 부족을 검증한다. 모델 fit/train/predict 호출은 차단한다. 원본/개발/최종 모델과 예측의 해시를 보호하고 저장 결과를 별도 프로세스에서 재계산한다. 기존 평가/최종 파일을 변경하지 않는다. 공개 보고서에는 집계와 판단만 기록하며 개별 ID/예측/데이터 출력은 로컬에 둔다. 공식 제출과 push는 없다.

## 실제 수행과 검증

정규 CPython 3.13.1에서 합성 계약 6개를 통과하고 2026-10-22 14:21 KST에 본 진단을 완료했다. 별도 프로세스 재검산도 같은 결과와 판단을 재현했다. 각 프로세스의 종료 코드는 0이다. 저장된 R3/R4 전체 W와 배분 합, 집합/k 분할 및 NumPy/Pandas 두 경로의 CF MAE가 허용오차 안에서 일치했다.

모델 fit/train/predict 호출을 차단했으며 실제 적합/추론은 0회다. 기존 P-006 개발 참조와 P-011 최종 모델/전체 출력의 해시가 유지됐다. 사전 보고서와 실행 코드는 로컬 사본으로 보존했다. V2와 제공 평가 구간을 다시 채점하지 않았다.

## 해석, 후속 판단과 종료

짧은 기록 집단의 절대 CF MAE가 비교 집단보다 큰 경우가 있어도, P-006이 B3 대비 악화했는지는 별도 질문이다. 이번에는 짧은 집단의 평균/중앙 CF 오차가 모두 개선됐고 악화 개소는 절반 미만이었다. 따라서 이번 기준과 표본에서 짧은 이력의 반복 악화 가설은 지지되지 않는다. 이는 짧은 이력이 모든 조건에서 안전하다거나 범주 정규화 강화가 절대 효과 없다는 입증은 아니다.

R4의 양의 배분 W는 개별 오차 개선과 집합 비용 악화가 함께 나타날 수 있음을 보여 준다. 용량 가중과 집합 상쇄/오차 방향이 함께 작용하는 수치이므로 짧은 이력의 과적합 원인으로 확정하지 않는다. 기록 길이와 발전소/지역/기상/편입 시점의 교란도 남는다.

사전 후속 조건은 네 비교 모두 미통과이며 `regularization_evidence=false`로 기록됐다. 사용자가 승인한 조건부 실행안에 따라 **P-003 범주 정규화 실험을 시작하지 않고 P-006 개발 우선 및 로컬 최종 산출물을 유지한다.** 결과를 보고 경계/지표를 바꾸거나 정규화 대신 다른 후보를 즉시 탐색하지 않는다. P-012는 이 범위에서 완료한다. R4 날짜 취약성과 독립 미래 검증 부재는 여전히 남으며 새 원인 질문을 필수로 올리지 않는다.
