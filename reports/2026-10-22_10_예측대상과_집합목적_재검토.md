# 예측 대상과 집합 목적 재검토

작성: 2026-10-22 KST. 상태: 배포 과제 설명, 기존 결과와 평가 코드의 읽기 검토 완료. 새 데이터 집계, 통계 분석, 학습, 추론과 제출은 수행하지 않았다.

## 질문과 목적

사용자는 최근 결과를 어떻게 판단하고 무엇을 중시해야 하는지, 실제 예측 대상을 기준으로 다시 생각하도록 요청했다. 개별 발전소 오차를 다룬 P-012의 종료 판단과 전체 과제의 개선 방향을 구분한다. P-006을 현재 후보로 유지하면서 다음 검토의 초점을 집합 발전량과 정산 오차로 둔다.

## 사용 범위와 수행 방법

로컬 배포 README의 과제/출력/정보 시점, 기존 검증 설계, P-007의 목적함수 비교, P-006/P-010/P-012 보고서, 실제 목표와 점수 함수를 대조했다. 배포 문서는 로컬에 보존하며 원문이나 데이터 행을 이 보고서에 복제하지 않는다. 아래 수치는 기존 보고서의 결과이며 이번에 다시 계산하지 않았다. 수식 분해는 평가 정의에서 도출한 항등식이며 실제 비용 비율의 측정 결과가 아니다.

## 실제 예측 대상

대상일 전날 17:00 KST까지 주어진 정보로 G1/G2 각각의 다음 날 시간별 발전량(kWh)을 예측한다. 평가 시각은 2025-06-01 01:00부터 2026-06-01 00:00 KST까지 8,760개다. 253개 발전소를 두 집합에 빠짐없이 한 번씩 배정하고 평가 1년 동안 구성을 유지하며, 각 집합의 설비용량은 20,000 kW 이상이어야 한다. 기존 current_group은 변경 가능한 참조 배정이다.

개별 발전소의 발전 비율 CF는 현재 모델이 사용하는 중간 목표다. 최종 점수에 들어가는 것은 집합별 kWh 오차다. 가격과 시간대 가중치는 제공된 평가 가중이며 별도의 SMP 예측이 목표가 아니다. 대상일 실측 기상과 평가 기간 발전량은 입력으로 쓸 수 없다.

집합 g의 잔차를 E(g,t)=예측 합계-실제 합계, q(t)=SMP(t)×k(t)라고 두면 다음과 같다.

```text
W = Σ_t q(t) × (|E(G1,t)| + |E(G2,t)|)
S = R - 0.10 × W
```

모든 발전소와 같은 시각을 유지하는 비교에서는 전체 실제 발전량의 가격 합 R이 동일하다. 따라서 W 감소가 정산금 증가에 해당한다. 오차 방향의 벌점은 대칭이며, k는 KST 종료 시각 11~15시에 3이고 나머지는 1이다. G1/G2 사이의 반대 방향 오차는 채점에서 상쇄되지 않는다.

## 최근 결과가 말하는 것

| 근거 | 확인한 사실 | 판단에 주는 의미 |
|---|---|---|
| P-006 | B3 대비 T0/V1/R3/R4 W가 각각 1.9453%/1.0002%/2.9666%/0.0307% 감소 | 발전소 ID를 포함한 현재 모델은 개발 후보로 유지할 근거가 있다. 네 구간은 독립된 네 시험이 아니다. |
| P-010 | R4는 날짜 블록 하나를 제외하면 순개선 방향이 바뀌는 경우가 있었다 | 작은 전체 개선만으로 계절 안정성이나 미래 개선을 확정하지 않는다. |
| P-012 | R4 짧은 관측 월 집단의 평균 CF MAE는 0.030478에서 0.029919로 감소했지만 W 변화 배분은 +910,468.37 | 개별 오차 개선이 집합 비용 개선을 보장하지 않는다. 해당 배분은 과적합 원인이나 독립적인 집단 효과의 증명이 아니다. |
| B4/B5/B6/H1 이력 | 고정 편향 보정, 용량/가격 가중, 교차 특징은 각각 정한 후속 기준을 통과하지 못했다 | 점수와 관련 있어 보이는 가중치나 특징을 더하는 것만으로 해결된다고 가정하지 않는다. |

P-012는 짧은 이력의 반복 악화라는 특정 가설을 지지하지 않은 결과다. 현재 모델에 개선 여지가 없다는 결론은 아니다. 개별 CF 동일 가중 L1과 집합 kWh 절대오차 사이의 차이가 남으며, ID 추가도 이 차이를 직접 해소하지 않는다.

## 중시할 순서와 설계상의 빈틈

1. **집합별 시간 오차와 W:** 개별 CF MAE는 문제를 찾는 보조 지표로 사용한다. 채택 판단은 동일 표본/가격/구성의 W와 사전 안정성 기준을 따른다. 용량이 다른 발전소의 동일 CF 오차도 집합 kWh 영향은 다르다.
2. **여러 발전소가 함께 틀리는 방향:** 같은 시각에 오차가 한쪽으로 쌓이면 집합 오차가 커진다. 발전량 자체의 상관과 모델 잔차의 상관을 구분해야 한다. 높은 발전량 상관만으로 배정이나 모델 분리를 결정할 수 없다.
3. **비용이 큰 시각과 기간 간 재현:** 가격×k와 집합 오차를 함께 본다. 피크만 개선하고 다른 시기의 비용을 늘리거나, R3의 개선으로 R4 악화를 가리는 변경은 피한다. 과거 모델에서 나온 비용 집중 비율을 현재 모델의 비율로 재사용하지 않는다.
4. **전체 253개소와 정보 시점:** 최종 대상의 학습 기록이 있다는 사실과 그 전체 구성의 미래 1년 성능을 검증했다는 주장은 다르다. 결측 발전량을 0으로 채워 집합 정답을 만들거나 검증 기간 실적을 입력에 넣지 않는다.
5. **구성이라는 별도 결정:** 현재 구성은 적법한 참조안이지만 최적이라는 근거는 없다. 구성과 모델을 동시에 바꾸면 개선의 출처가 불명확해지므로 각각의 비교를 분리한다.

집합 발전량 직접 예측 또는 과거 시간 순서 밖 예측 잔차를 이용한 집합 보정은 목적에 가까운 설계 후보다. 다만 전체 구성의 장기간 완전 정답 부족, 변화하는 관측 구성, 보정 학습에 사용할 과거 예측의 가용성이 먼저 해결되어야 한다. 집합 직접 모델이 현재 방식보다 우수하다는 결과는 없으며 B4의 고정 보정을 새 후보처럼 반복하지 않는다.

## 다음 후보 P-013: 집합 비용의 두 성분 확인

다음 질문은 현재 예측에서 전체 발전소를 합쳐도 남는 순오차와, 두 집합의 개별 정산으로 추가되는 비용 중 무엇이 주된 개선 과제인지다. 신규 독립 후보로 등록하되 이번에는 계산하지 않는다. EDA-004의 발전량 공동 변동이나 EDA-012의 흐림 대비 불확실성과 대상이 다르다. 과거 B0 잔차 분석과도 달리 현재 P-006/B3를 동일 평가 목적에서 대조한다.

같은 시각과 고정 개별 예측에서 다음 항등식이 성립한다.

```text
T(t) = q(t) × |E(G1,t) + E(G2,t)|
D(t) = q(t) × (|E(G1,t)| + |E(G2,t)| - |E(G1,t) + E(G2,t)|)
W = Σ_t T(t) + Σ_t D(t),  D(t) >= 0
```

T는 해당 표본의 전체 순오차 비용이다. 개별 예측을 고정한 채 발전소만 재배정할 때 변하지 않는 하한이다. T가 크다고 모든 발전소가 같은 방향으로 틀렸거나 원인이 예보라고 확정할 수는 없다. D는 두 집합의 반대 부호 잔차를 별도 정산해 발생하는 추가 비용이다. 용량 제약과 연중 고정 배정 때문에 D 전체를 제거하는 배정이 존재한다는 보장은 없다. T를 공식 점수로 대신 사용해서도 안 된다.

후속 실행 범위는 기존 T0/V1/R3/R4 고정 주 표본과 저장 P-006/B3 예측으로 제한한다. 그룹별 과대/과소 비용, k=1/3, 월별 T/D 및 두 모델의 변화액을 한 번 산출하고 합이 기존 W를 재현하는지 별도로 검산한다. T0/V1/R3/R4는 서로 다른 개소/기간이므로 절대액을 직접 합치거나 순위화하지 않는다. 각 구간 안의 비교와 비중을 사용하고, 겹치는 기간을 독립 반복으로 세지 않는다.

이후 판단은 전체 순오차가 반복되는 조건이면 고정 구성에서 집합 예측/보정의 학습 가능성을 먼저 검토하고, 분리 비용이 반복적으로 남으면 예측을 고정한 구성 연구의 필요성을 검토하는 것이다. 신호가 구간마다 다르면 우선순위를 확정하지 않고 종료한다. 현재 결과를 보고 유리한 월이나 지표만 고르는 탐색, 새 후보 학습, 구성 최적화는 이 진단에 포함하지 않는다. 어느 방향이든 실험 착수 전 별도의 단일 변경, 과거 학습 범위와 채택/중단 기준이 필요하다.
