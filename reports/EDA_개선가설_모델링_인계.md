## 조건과 계산 계약

조건 8개는 평균 A/B 17시 운량 20/80%, 제공사별 17시 강우량 0/1 mm, 제공사별 운량 17-10시 차이 -20/+20 %p, A17-B17 운량 차이 -20/+20 %p, A17/B17 양수 강우 발생과 A10/A17 양수 강우 발생이다. 정확한 경계 포함 방향과 결측 기준은 EDA 보고서의 사전 표와 `conditions()`를 따른다. 결과를 보고 다른 경계를 찾지 않았다.

운량은 %, 차이는 %p다. `wa_rain`/`wb_rain`은 mm의 강우량이고 `wb_total_liq`는 물환산 총 강수량이다. B3의 기존 입력은 B rain이 아니라 total_liq다. 예보의 적산 구간은 제공 README만으로 확정할 수 없으므로 mm/h로 바꾸거나 A/B 양의 차이를 같은 물리량의 오차로 쓰지 않는다. 강수 발생은 각 제공사 값이 양수인지로만 비교했다.

주 진단은 KST 시작 09~16시 및 태양고도 15도 이상이다. cf는 1시간 발전량/용량, 잔차는 예측-실제다. 개별 조건 비율은 용량 가중으로 계산했다. 날짜 20일 미만 또는 A/B 어느 쪽 지점이 5개 미만이면 작은 표본이다. 행/발전소/공유 지점/지점-날짜/지점 쌍을 구분하며 반복 행을 독립 표본으로 세지 않았다.

공유 셀은 같은 월/시작 시간/태양고도 `[15,30), [30,50), [50,∞)`이며 조건과 나머지에 각각 5일 이상 있는 셀만 동일 비중으로 비교했다. 이 사후 셀 평균을 모델 입력으로 재사용하지 않는다. 집합-시각 날씨는 용량 가중 평균, 변수 유효/주 진단 용량 하한 95%, 집합 강수 발생은 유효 용량의 50% 이상에서 양수일 때로 고정했다. T0 조인 누락 A17 64행/B10 1,840행은 결측 조건에 보존했다.

W는 `Σ(g,t)SMP(t)k(t)|Σ(i∈g)(prediction-actual)|`다. G1/G2는 먼저 합치지 않는다. 집합-시각 조건에 따른 W 분할과 `q×sign(E전체)×부분 잔차 합`의 부호 기여를 각각 검증했다. 기존/추가 표본의 독립 W나 발전소별 날씨 부분 W를 더하지 않는다. 월/시간/k 분할과 과대/과소 비용 합도 보존했다.

## 개선 가설 H1: 운량과 태양/계절의 교차 표현

**최우선이자 유일한 가설이다.** 같은 월/시간/태양고도 셀에서 흐림의 예측 하락폭이 실제 하락폭보다 큰 상대 대비가 네 구간과 두 집합, R3/R4 기존/추가 표본에서 반복됐다. 이 관계를 나무가 더 적은 분할로 표현하게 하면 조건부 잔차와 전체 W가 줄어들 수 있다는 가설이다. 성능 개선이나 원인 판정은 아직 아니다.

기존 B3는 A/B 운량 10/17시 원시 열, cosz, 연중 날짜 sin/cos 등을 39개 특징에 따로 넣는다. 다음 제안은 새 관측 정보가 아니라 **기존 정보의 결정론적 교차 표현 3개**를 추가하는 것이다. 원시 날씨에 정보가 더 생기거나 B3가 현재 관계를 전혀 학습하지 않았다고 주장하지 않는다. 라운드/제공사 혼합 가중과 고정 잔차 보정은 적합하지 않는다.

발전소 i, KST 종료 시각 t에 대해 다음과 같이 정의한다.

```text
A = wa_cloud_r17(i,t) / 100
B = wb_cloud_r17(i,t) / 100
m = (A+B) / 2
z = max(B3의 기존 cosz(i,t), 0)
d = dayofyear(KST ts)  # 기존 B3와 같은 종료 시각 기준
s = sin(2*pi*d/365.25) # 기존 doy_sin과 같은 식
c = cos(2*pi*d/365.25) # 기존 doy_cos와 같은 식

cloud_solar      = m*z
cloud_solar_sin  = m*z*s
cloud_solar_cos  = m*z*c
```

세 특징은 무차원이다. cosz는 기존 baseline의 구간 중앙 태양기하 값을 그대로 쓴다. 주 진단의 태양고도 15도나 운량 80% 경계를 모델의 행 제거/보정/특징 경계로 옮기지 않는다. 다른 변수나 추가 교차항은 이번 H1에 섞지 않는다. 기존 39개를 같은 순서로 유지하고 위 이름 3개를 이 순서로 붙이는 42개 계약을 제안한다.

| 항목 | 제안 계약 |
|---|---|
| 결측/범위 처리 | A 또는 B 원시 운량이 NaN/비유한/0~100% 밖이면 추가 3개만 NaN. 원시 39개 열과 기존 처리/행은 유지한다. 한쪽 운량으로 평균을 대체하거나 0으로 채우지 않는다. cosz가 비유한이면 계약 오류로 중단한다. 출력은 float32로 고정한다. |
| 학습 내 적합 | 새 특징의 경계/평균/분위수/정규화 계수는 적합하지 않는다. 100과 365.25는 정의 상수다. 모델 계수/나무만 각 구간 기존 학습 마감 이전 행에서 적합한다. 검증 전체의 셀 평균/잔차/사후 분위수를 사용하지 않는다. |
| 예측 시점 가용성 | 대상일 전날 17시 발행 예보, 정적 위경도, 이미 알려진 대상 시각으로 계산 가능하다. 대상일 실측, 발전량, 미래 잔차나 평가 기간 가격을 요구하지 않는다. |
| 기대 효과 | 운량과 태양/계절에 따른 함수 표현을 바꿔 흐림의 상대 잔차 대비와 전체 집합 W를 줄일 가능성. 일정 방향의 예측 상승/하락을 강제하지 않는다. |
| 실패 조건 | 기존 분할로 이미 충분히 표현해 전체 W가 개선되지 않거나, 잔차 차이가 지역/운영 구성에 따른 교란이면 실패한다. 조건 오차만 줄고 전체 W/안정성 계약을 통과하지 못해도 미채택한다. 원시 결측과 새 NaN 처리가 예상 계약과 다르면 계산부터 중단한다. |

강수/불일치용 H2/H3는 만들지 않았다. 작은 집합 표본이나 기간별 방향 변화만으로 가설 수를 채우지 않는다.

## 후속 모델링 제안 계약

이 절은 **미실행 제안**이다. 모델링 세션에서 입력/코드/환경과 저장 B3를 확인한 뒤, 점수를 보기 전에 별도 실행 보고서와 성능 계획에 계약을 고정한다. 이번 세션은 여기서 종료한다.

1. 실험 H1 하나만 수행한다. B3 동일 비중 L1, 기존 600트리/모델 설정, 원시 39개 특징/두 기압 열, 목표 `clip(energy/cap,0,1.2)`, 기존 태양고도 >0 학습 선택, 야간/음수 예측 0과 상한 미적용을 유지한다. sample_weight, 튜닝, 보정, 집합 재배정은 변경하지 않는다. 변경 축은 위 교차 특징 3개뿐이다.
2. T0/V1/R3/R4에서 각각 1회, **기본 총 4회 적합**한다. 같은 학습 경계의 B3 저장 예측을 재사용한다. 계약 불일치로 참조 재적합이 꼭 필요하면 사유를 먼저 기록하고 최대 8회로 재고정한다. 결과가 나쁘다는 이유의 재적합/난수/설정 탐색은 허용하지 않는 제안이다.
3. 학습 경계는 아래와 같다. s는 KST `ts-1h`이고 cutoff는 ts 기준 00:00을 포함한다. 발전소 ID와 정답/가격/구성/시각 격자는 기존 계약 그대로 고정한다.

| 구간 | 학습 s 시작 이상 | 학습 ts 마감 이하 | 채점 고정 표본 |
|---|---|---|---|
| T0 | 2022-01-01 | 2022-12-31 00:00 | 기존 80개소 |
| V1 | 2022-01-01 | 2023-12-31 00:00 | 기존 148개소 |
| R3 | 2022-07-01 | 2024-06-30 00:00 | 기존 R3 완전 224개소 |
| R4 | 2022-10-01 | 2024-09-30 00:00 | 기존 R4 완전 252개소 |

4. 채택 기준은 T0/V1 연간 W 각각 감소, 두 연간 표본의 어느 분기도 5% 초과 악화 없음, R3/R4 분기 W 각각 감소 및 그 두 구간의 어느 월도 5% 초과 악화 없음이다. 상대 동률 허용오차 1e-12를 유지한다. 조건별/월별/집합별/k별/기존-추가 표본 결과와 과대/과소 비용을 함께 남기되 사후 기준 추가/변경은 하지 않는다. 정답/구성이 같으므로 R은 같고 W가 낮을수록 S가 높다.
5. H1의 진단은 같은 고정 8개 조건과 흐림 공유 셀 대비를 재사용한다. 조건 성능만 좋아져도 전체 계약을 통과하지 못하면 B3를 유지한다. 전체 253개소의 짧은 공통 정답 구간은 별도 진단이며 연간 표본과 합치거나 채택 기준으로 추가하지 않는다.
6. 새 특징의 시간 가용성/결측 처리와 42개 순서, 학습 행/경계, 예측 키와 격자, 저장 파일/모델 해시 및 실제 적합 횟수를 검증한다. 이미 본 개발 자료의 재사용으로 일반화 성능이 보장되지는 않는다. V2/제공 평가 구간은 후보 선택/튜닝/새 예측에 사용하지 않는다.
7. 예산을 마친 뒤 통과 여부와 불확실성을 기록하고 종료한다. H1 실패 시 B3를 유지하며 H2나 다른 EDA로 자동 전환하지 않는다. 공식 제출/push는 별도 사용자 요청 없이 실행하지 않는다.

## 종료 상태

EDA-011 완료, H1 제한 비교에 한해 모델링 가능이다. 기본 EDA 종료, 기존 선택 3개/보류 5개와 B3 참조를 유지한다. [EDA 계획](EDA_진행계획.md)의 새 EDA-012는 선택 후보이며 모델링의 선행 필수 조건이 아니다. [성능 계획 P-002](성능개선_진행계획.md)는 EDA/가설 인계 완료, 모델 비교 대기로 갱신한다. 다른 세션 생성이나 메시지 전송은 하지 않았다.
