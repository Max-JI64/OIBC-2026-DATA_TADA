# EDA 진행 계획과 추가 질문

작성: 2026-10-21 KST. 갱신: 2026-10-22 KST

현재 작업 방향: [DA-012 발전 유형별 기상 반응](2026-10-21_15_발전유형별_기상반응_차이_분석.md)까지의 결과와 B3 설계를 대조한 [종합 점검](2026-10-22_01_분석결과_종합과_현재모델_설계점검.md)을 완료했다. 기본 EDA 종료와 기존 선택/보류는 유지한다. 이후 사용자 재개 지시로 별도 [P-006 모델 비교](2026-10-22_03_P006_발전소ID_범주입력_비교.md)의 4회 적합/저장 검증을 완료했으며 EDA를 재개한 것은 아니다.

상태: EDA-001과 EDA-002를 완료해 정한 기본 EDA 범위를 종료했다. EDA-011의 저장 예측 분석과 가설 인계를 완료했다. 현재 진행 항목은 없다. 기존 선택 후보 3개/보류 5개는 유지하며 새 선택 후보 EDA-012 한 개를 별도로 등록했다. EDA 단계에서는 H1 제한 비교를 모델링 가능으로 인계했다. 후속 [P-005 모델 비교](2026-10-21_04_H1_운량_태양계절_교차특징_비교.md)는 미채택해 당시에는 B3를 유지했다. 현재 개발 우선 후보는 별도 성능 계획의 P-006이며 추가 EDA는 실행하지 않았다.

최신 연결: [전체 작업 재검토](2026-10-22_08_전체작업_재검토와_현재판단.md)와 별도 P-009/P-010/P-011을 완료했다. 고정 P-006의 로컬 최종 적용을 완료했으며 이 계획의 새 EDA나 보류 원인 규명은 실행하지 않았다.

## 목적과 현재 범위

데이터의 형태와 관계를 이해하는 EDA만 진행한다. 머신러닝 학습, 발전량 예측, 최종 변수 선택, 최종 전처리 적용, 집합 최적화와 제출은 이번 범위에 포함하지 않는다. 원본 데이터는 유지한다.

처음부터 세부 EDA 목록을 모두 확정했던 것은 아니다. 데이터 형태에서 관계로 넘어가는 순서로 진행하면서 빠진 범위와 발견한 문제를 보완했다. 이 문서부터는 예정 작업과 새로 발견한 질문을 구분하고, 질문마다 수행 이유와 종료 기준을 먼저 기록한다.

기본 EDA의 주요 범위는 이미 확인했다. **EDA-001 지표기압 추가 점검과 EDA-002 결과 정리를 완료해 이번 기본 EDA를 마무리했다.** 선택 및 보류 항목은 기본 EDA 종료의 필수 조건이 아니다. 새 근거로 필요한 질문이 생기면 이 문서에 먼저 기록하고 범위와 종료 기준을 정한 뒤 별도로 진행한다.

사용자 요청으로 작성한 후속 산출물은 [검증과 데이터 처리 설계안](2026-10-19_18_검증과_데이터처리_설계.md)이다. 설계 문서 작성은 EDA 재개나 모델 실행을 뜻하지 않으며, 이 목록의 상태와 기본 범위 종료 판단은 유지한다.

선택 항목의 등록은 실행 지시가 아니다. EDA-003~010을 모두 완료해야 기본 EDA가 끝나는 것도 아니다. 기존에 완료한 A/B 직접 비교와 B 운량 패턴 반복 확인을 다시 미실행 작업으로 취급하지 않는다.

최초 등록한 분석 질문의 발견일과 결과 정리 필요성을 기록한 날짜는 모두 2026-10-19다. 출처는 각 행의 근거 보고서로 연결했다. EDA-001과 EDA-002는 결과와 종료 판단을 연결했다. 선택/보류 질문의 후속 작업은 미실행 상태이며, 재개해 완료하면 해당 행에 결과 링크와 종료 판단을 추가한다.

EDA-011은 2026-10-21에 별도로 등록한 후속 모델 잔차 질문이다. 위의 최초 등록일 설명은 EDA-001~010의 이력이다. EDA-011은 실행 전 계약 고정 후 한 항목으로 진행해 완료했다. 흐림의 공유 셀 잔차 대비 반복과 절대 방향 변화를 구분해 H1 하나를 인계했다. 기존 기본 EDA의 종료 판단과 선택/보류 항목의 상태는 바꾸지 않았다.

## EDA-001의 실행 범위

질문은 “A 지표기압의 차이는 언제부터 어떤 형태로 나타났으며 여러 지점과 두 예보 라운드에서 공통적인가?”로 제한한다.

- 기존 월별/지점별 결과를 출발점으로 사용하고 평가 구간의 2025년 11월~2026년 5월을 일/주별로 살핀다. 학습 구간은 비교 기준으로 사용하며 선택한 기준과 한계를 보고서에 적는다.
- 두 라운드와 제공 A 지점의 시간 흐름, 지점 사이 산포 및 값 범위를 확인한다. 전후 비교가 필요하면 발견한 경계 또는 변화 구간에 대해 한 차례 수행한다.
- 핵심 그림은 최대 3개로 제한한다. 검증에는 키, 시간축, 지점/라운드 집계와 원본 유지 확인을 포함한다.
- 뚜렷한 시작일이 없거나 연속 변화라면 그 사실과 가능한 시간 범위를 기록하고 종료한다. 시작일을 반드시 하나로 정하거나 생성 원인을 반드시 밝히려고 분석을 늘리지 않는다.
- 기압 자동 보정, 자료 삭제, 외부 기상 자료를 통한 원인 추적과 모델 기반 변화점 탐지는 이번 항목에 포함하지 않는다. 다른 질문이 생기면 새 ID로 먼저 기록한다.

이번 실행의 비교 기준은 학습 2024-11~2025-05와 평가 2025-11~2026-05다. 완전한 24시간이 있는 지점-날짜의 일평균을 사용하고, 지점 간 같은 날 중앙값을 뺀 공간적 차이도 함께 본다. 학습 비교 구간 전체의 지점별 상대 평균 수준을 참고 기준으로 두되 서로 다른 해의 실제 날씨를 맞춘 것으로 해석하지 않는다. 변화 후보는 두 라운드의 지점별 상대 수준 전일 변화 절댓값 중앙값을 평균해 가장 큰 날짜 하나로 정하고, 그 날짜 전후 7일을 한 차례 비교한다. 이 기준은 기술통계용 후보이며 오류나 공급 방식 변경의 확정일이 아니다.

## 새로 생긴 질문을 기록하고 진행하는 방법

1. 새 질문을 발견하면 다음 실험 전에 이 문서에 새 ID를 부여한다. 기존 질문과 같으면 새 행 대신 기존 행의 범위와 이력을 갱신한다.
2. 발견일, 출처 보고서 또는 부모 작업 ID, 질문, 필요성, 예상되는 해석 영향, 우선순위, 상태, 수행 범위와 종료 기준을 적는다. 아직 출처 보고서가 없으면 진행 중인 작업 ID와 발견 근거를 짧게 적는다.
3. 현재 질문에 답하는 데 직접 필요한 검증은 현재 항목의 범위에 기록한다. 독립적인 새 질문은 우선 후보로 등록하며, 발견 즉시 연달아 실행하지 않는다.
4. 현재 작업을 마친 뒤 후보의 우선순위를 검토한다. 자료 연결과 해석을 잘못하게 만드는 문제를 우선하고, 추가 근거가 없거나 활용 목적이 불명확하면 보류한다. 필수 작업으로 올릴 때는 어떤 기존 결론이나 자료 사용 판단이 달라질 수 있는지 근거를 기록한다. 원인을 모른다거나 다른 조건을 아직 보지 않았다는 이유만으로 필수 작업을 늘리지 않는다.
5. 동시에 진행하는 EDA 항목은 하나로 유지한다. 상태를 `후보`, `대기`, `진행`, `완료`, `보류`로 관리하고, 우선순위를 바꾼 이유와 범위 확대를 아래 이력에 남긴다.
6. 완료 시 결과 보고서 링크와 종료 판단을 남긴다. 질문에 답했거나 자료 한계로 더 답하기 어렵다는 판단도 종료 사유다. 완료 항목을 지우지 않는다.

새 항목은 다음 형식으로 작업 목록에 추가한다.

```text
ID: EDA-다음번호
발견일 / 출처 또는 부모 ID:
질문:
추가 점검이 필요한 이유와 해석에 미치는 영향:
우선순위 / 상태:
수행 범위:
종료 기준:
결과 보고서 / 종료 판단: 미실행
```
