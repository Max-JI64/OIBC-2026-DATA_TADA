# 데이터 분석 진행 계획

작성: 2026-10-21 KST

현재 단계: DA-003 조건부 관계 분석을 정한 범위에서 완료했다. [결과 보고서](2026-10-21_07_기상조건과_발전량의_조건부관계_분석.md)에 단독/공동/UV 제외 관계, 날짜 블록 구간과 재현, 지지 표본 및 한계를 기록했다. 현재 진행 항목은 없으며 다음 우선 후보는 DA-002 발전소 유형이다. DA-001 완료와 요인 대체 판단 보류, 예측 모델링 중단을 유지한다.

## 목적과 범위

데이터 자체의 구조와 관계를 이해한다. 분석마다 무엇을 알게 됐는지와 어느 조건에서 결론이 유지되는지를 먼저 판단한다. 모델 성능 개선 가능성은 별도 가설로 남기며 분석의 성공 조건으로 삼지 않는다.

사용자가 든 FA는 분석 방법의 예시다. 방법을 나열해 모두 적용하기보다 질문에 맞는 방법을 선택한다. 요인, 군집과 설명 목적의 통계모형은 적합할 수 있지만, 현재 단계에서 발전량 예측모형을 학습하거나 예측 파일을 생성하지 않는다. 기존 B3와 모델링 결과는 보존한다.

기본 EDA의 완료 이력은 [기존 계획](EDA_진행계획.md)에 유지한다. 기존 EDA 질문을 심화할 때는 부모 ID와 겹치는 범위를 명시해 같은 분석을 반복하지 않는다. 기존 모델 잔차의 설명에만 분석을 한정하지 않는다.

## 첫 작업 DA-001의 준비 범위

실행 전 독립 보고서에 기간, 변수 목록, 단위, 표본 구성, 결측 처리와 검증 기준을 고정한다. 아래는 준비 방향이며 실행 계약의 확정이나 계산 결과가 아니다.

- 기존 2024년 관계 EDA 표본을 시작 후보로 둔다. 재현 기간은 실제 기록 가용성을 확인한 뒤 고정한다. 이미 모델 개발에 사용한 기간을 새로운 독립 시험 자료라고 부르지 않는다. V2와 정답 없는 평가 기간은 이번 시작 범위에 넣지 않는다.
- 기상 분석의 관측 단위는 고유 기상 지점과 시각이다. 발전소에 조인한 기상값을 발전소 수만큼 독립 관측으로 세지 않는다. A/B 지점 쌍 분석으로 확장할 때도 공유 지점의 반복을 고려한다.
- A의 동일한 기온 계열과 B의 거의 중복된 강수 계열을 먼저 확인한다. 상수와 중복 열을 포함한 행렬에 FA를 그대로 적용하지 않는다. 이번 분석용 변수 구성과 원본 수정은 구분한다.
- 전체 수준과 지점/달력 구성을 고려한 편차를 구분한다. 요인이 계절, 시간대 또는 자료 가공 패턴을 요약한 것인지 함께 확인하며 처음부터 물리적 기상 원인의 이름을 붙이지 않는다.
- 강수의 0 집중, 시정/운고 집중값과 원형 풍향은 일반 연속형 변수와 같게 취급하지 않는다. 변수별 변환/제외/민감도 범위는 적용 전에 정한다. 풍향 sin/cos를 독립 측정 두 개로 해석하지 않는다.
- 표준화, 상관행렬의 수치 안정성, KMO 등의 진단과 요인 수 선택을 함께 검토한다. 큰 표본의 Bartlett 검정 유의성 하나로 적합성을 선언하지 않는다. 시간과 공간의 의존성을 고려한 재표집 또는 분할 재현 방식을 사전에 정한다.
- PCA는 전체 분산의 요약 비교로 두고 FA의 공통요인 해석과 구분한다. 추정과 회전 방법, 요인 수 비교 범위, 수렴과 부적절해 점검을 먼저 정하며 안정적 구조가 없다는 결과도 허용한다.

FA의 추정과 회전 방법은 [statsmodels 공식 문서](https://www.statsmodels.org/stable/generated/statsmodels.multivariate.factor.Factor.html)를 참고한다. PCA와 FA의 방법 구분은 [scikit-learn 공식 문서](https://scikit-learn.org/stable/modules/decomposition.html)를 참고한다. 방법 문서만 확인했으며 현재 설치 패키지와 실제 실행 가능성은 아직 점검하지 않았다.

## 진행과 기록

한 번에 한 분석을 진행한다. 후보를 시작할 때 상태를 `진행`으로 바꾸고 `reports/YYYY-MM-DD_NN_분석주제.md`에 질문, 사용 범위, 방법과 종료 기준을 기록한다. 새 질문은 다음 실험 전에 부모 항목과 함께 등록한다.

완료 보고서에는 데이터에 대한 결론, 결론의 지지 범위와 미확정 사항을 담는다. 모델링 활용 아이디어는 마지막에 가설로만 구분하며 곧바로 모델 실험으로 넘어가지 않는다. 새로운 발전량 예측 실험은 사용자의 모델링 재개 지시 후에 다룬다.

원본 행과 전처리 행은 보고서에 복사하지 않는다. 데이터와 개별 결과 출력은 로컬에 보관한다. 공개 가능한 코드, 보고서와 로그만 명시적으로 스테이징해 로컬 커밋한다.
