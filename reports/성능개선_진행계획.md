# 성능 개선 진행 계획

작성: 2026-10-20

현재 목표: 제출 전까지 검증 근거를 쌓으며 예측 성능을 개선한다. 사용자 요청으로 제출 준비 중심의 흐름에서 모델 개선으로 돌아왔다. 기존 B3 최종 학습/예측 파일은 중간 후보의 고정 산출물로 보존하며 최종 방법 확정이나 분석 종료로 취급하지 않는다.

## 현재 검증과 운영 원칙

- P-004의 사전 기준에 따라 B3를 현재 우선 참조로 둔다. B5의 기존 연간 개선과 여름 개선은 보존하되 후반기 비교에서는 개선이 일관되지 않았다. T0/V1/R3/R4는 이미 본 개발 자료이며 독립 시험이라고 표현하지 않는다.
- 연간 W와 분기 안정성을 주 판단으로 쓰고 월, 집합, k 및 전체 253개소의 짧은 공통 구간도 함께 기록한다. 개별 MAE 개선만으로 방법을 채택하지 않는다.
- 이미 확인한 V2와 정답 없는 제공 평가 구간은 이번 후보 선택과 반복 튜닝에 사용하지 않는다. 필요한 검증 설계 변경은 이유와 사용 이력을 먼저 기록한다.
- 현재 방법이 개선되지 않아도 제출 준비로 자동 전환하지 않는다. 실험 결과를 검토해 다음 가설의 우선순위를 정한다. 새 EDA는 [EDA 계획](EDA_진행계획.md)에 등록하고 한 항목씩 진행하며 기존 기본 EDA 완료와 보류 이력은 유지한다.
- 원본과 이전 모델/예측은 보존한다. 실험마다 설정, 입력/코드 해시, 실제 적합 횟수와 결과를 기록하고 코드/중간보고서를 로컬 커밋한다. 공식 제출과 Git push는 하지 않는다.

## 갱신 이력

- 2026-10-20: 사용자 요청으로 성능 개선 작업을 계속하는 목표를 기록하고 P-001을 시작했다. B3 참조/기존 산출물 보존, V2 재사용 없음과 다음 후보 목록을 정했다.
- 2026-10-20: P-001의 4회 비교와 저장 검증을 완료해 B5를 개발 우선 후보로 남겼다. 전체 구성의 짧은 표본 악화를 기록하고 P-004의 추가 순차 검증 설계를 다음 우선으로 정했다. 원래 사전 계획은 실행 산출물에 별도 보존했으며 기본 EDA 종료와 기존 선택/보류 목록을 유지했다.
- 2026-10-20: 사용자 후속 요청으로 P-004를 시작했다. 시점은 2024년 3분기와 4분기로 고정하고 가용성 점검, 사전 기준 고정, B3/B5 네 번 적합 및 저장 검증 순서로 진행한다. 기본 EDA 상태는 변경하지 않는다.
- 2026-10-20: P-004의 학습, 저장 검증과 점수/판단 재현을 완료했다. 사전 조건에 따라 B3를 우선 참조로 되돌리고 P-002의 예보 조건별 잔차 진단을 다음 우선으로 정했다. 사전 보고서와 계획 사본은 별도 보존했으며 기본 EDA와 보류 목록은 변경하지 않았다.
- 2026-10-21: 사용자 요청으로 EDA/개선 가설과 후속 모델링을 서로 다른 세션에서 수행하도록 인계 문서와 두 시작 프롬프트를 작성했다. EDA-011은 후보 등록만 했으며 모델링은 EDA 완료 인계를 읽은 뒤 실행한다. 새 분석과 학습은 하지 않았다.

- 2026-10-21: P-002/EDA-011의 기존 예측 분석과 검증을 완료했다. [모델링 인계](EDA_개선가설_모델링_인계.md)의 H1만 후속 세션의 제한 비교로 제안한다. B3 참조와 기본 EDA 종료/기존 선택/보류는 유지한다. 새 선택 EDA-012는 후보이며 이번에 실행하지 않았다. 새 학습/추론/보정/재배정, V2/평가 분석과 제출은 없다.
